Account Engagement での Agentforce の使用に関する考慮事項

Account Engagement で Agentforce アクションを使用するときは、次の考慮事項に留意してください。

必要なエディション

使用可能なエディション: すべての Account Engagement Edition (Salesforce Enterprise Edition、Performance Edition、および Unlimited Edition)

Account Engagement Agentforce アクションは Account Engagement からリリースされます。アクションをリリースする前に、外部クライアントアプリケーションと指定ログイン情報を作成する必要があります。

エージェントユーザー要件

  • Account Engagement Agentforceアクションごとに指定ログイン情報ユーザーとビジネス ユニットIDをエージェントに提供します。
  • 指定ログイン情報が認証されていない場合、アクションは実行されません。アクセス権を確認するには、指定ログイン情報を認証した後に、関連する呼び出し可能なアクションをテストすることをお勧めします。
  • エージェントユーザーには、Account Engagement アクションの強化に使用される Apex クラスへのアクセス権が必要です。アクセス権を付与するには、権限セットを手動で更新します。

Agentforce での Account Engagement 項目およびレコードの使用

  • エージェントが特定の Account Engagement 項目から値を取り込むようにするには、その項目をエージェントの指示に含めます。これは、リスト ID などのレコード ID で特に役立ちます。
  • Account Engagement アクションで使用される ID は、ほとんどの場合 Account Engagement ID 項目を参照します。見込み客レコードアクションには Account Engagement ID が含まれます。Salesforce レコードから ID を変換するには、追加アクションが必要です。
  • Account Engagement アクションでは、最後に更新されたレコードで並び替えられた 1,000 件のレコードのみが返されます。

Agentforce での Account Engagement アクションの使用

Agentforceアクションを使用して、専用のAccount Engagement Lead Managementエージェントを作成します。見込み客レコードを表示および更新し、Salesforce のどこからでもキャンペーンを育成できるように追加します。

必要なエディション

使用可能なエディション: すべての Account Engagement Edition (Salesforce Enterprise Edition、Performance Edition、および Unlimited Edition)
必要なユーザー権限
Account Engagement の Agentforce アクションをリリースする

Apex クラスのアクセス先:

  • getB2BEngagementStudioProgram
  • getB2BMarketingListMemberships
  • getB2BMarketingLists
  • signUpProspectB2BMarketingLists
  • upsertB2BProspect
  • viewB2BProspect

作業を開始する前に

  • 最新バージョンの Account Engagement (Pardot) AppExchange パッケージをインストールします。
  • Agentforce を有効にします。
  • 外部クライアントアプリケーションと指定ログイン情報を作成します。

アクションのリリースには最大 1 時間かかります。Agentforce アクションは、リリース後に削除できません。エージェントがアクションを使用するたびに、標準クレジットが消費されます。

  1. Account Engagement から Agentforce にアクションをリリースします。
    1. Account Engagement 設定を開きます。
    2. [Account Engagement の Agentforce アクション] で、[Deploy Actions] をクリックします。
    3. 選択内容を確認し、[閉じる] をクリックします。
  2. Salesforce で、Account Engagement アクションを Agentforce トピックに追加します。

Account Engagement APIを使用して、ビジネスニーズを満たすインテグレーションを作成します。サードパーティシステムでプロスペクトとビジターのデータにアクセスしたり、プロセスを自動化したりします。

    API を使用して、ビジネスニーズに合わせて Account Engagement を拡張します。開始にあたって役立つ一般的な使用事例のいくつかを次に示します。
  • トラッキング & 同意 API の使用
    追跡および同意 API では、ページビュー追跡プロセスの各ステップの機能が提供され、Account Engagement でページビューを追跡する方法を制御できます。ビジネスユニット設定で API を有効にしたら、開発者と協力してカスタムコンプライアンスソリューションを実装します。

トラッキング & 同意 API の使用

追跡および同意 API では、ページビュー追跡プロセスの各ステップの機能が提供され、Account Engagement でページビューを追跡する方法を制御できます。ビジネスユニット設定で API を有効にしたら、開発者と協力してカスタムコンプライアンスソリューションを実装します。

必要なエディション

使用可能なエディション: すべての Account Engagement エディション
必要なユーザー権限
トラッキング & 同意 API を有効にする Account Engagement の管理者ロール
  1. ビジネスユニットの設定を開きます。
    • Account Engagement で、 をクリックし、[設定] を選択します。
    • Lightning アプリケーションで、[Account Engagement 設定] を選択します。
  2. [編集] をクリックして、[トラッキング & 同意 JavaScript API を有効化] を選択します。
  3. 作業を保存します。

Account Engagementで追跡および同意APIを有効化すると、開発者が使用できるようになります。
