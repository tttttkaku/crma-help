Salesforce CMS への Account Engagement マーケティングコンテンツの追加

Account Engagementマーケティング資産をSalesforce CMSにコピーして、マーケティングキャンペーンで使用します。

必要なエディション

使用可能なエディション: Data 360 が有効になっている Account Engagement Growth Edition

Account EngagementマーケティングアセットをSalesforce CMSに追加するには、[CMSにコピー] を使用します。

  • Account Engagement ビジネスユニットの CMS へのコピーの有効化
    マーケティング担当者が今後のマーケティング キャンペーンでAccount Engagementマーケティング コンテンツを使用できるようにするには、SalesforceのCMSマーケティング ワークスペースにアセットをコピーできるようにします。アセットのコピーを有効にすると、新しいコンテンツワークスペースが作成されます。
  • Account Engagement ビジネスユニットから CMS ワークスペースへの送信済みメールのコピー
    今後のマーケティング キャンペーンにAccount Engagementメールを使用するには、CMSマーケティング ワークスペースにメールをコピーします。メールをコピーしても、Account Engagement のフォルダ権限は CMS ワークスペースに移行されません。
  • Account Engagement ビジネスユニットから CMS ワークスペースへのファイルのコピー
    今後のマーケティングキャンペーンにAccount Engagementファイルを使用するには、CMSマーケティングワークスペースにファイルをコピーします。ファイルをコピーしても、Account Engagement のフォルダ権限は CMS ワークスペースに移行されません。
  • CMS ファイルの種類
    次の種類のファイルをAccount EngagementビジネスユニットからSalesforce CMSにコピーできます。
  • Account Engagement ビジネスユニットから CMS ワークスペースへのフォームのコピー
    今後のマーケティングキャンペーンでAccount Engagementフォームを使用するには、フォームをCMSマーケティングワークスペースにコピーします。フォームをコピーしても、Account Engagement のフォルダ権限は CMS ワークスペースに移行されません。
  • Account Engagement ビジネスユニットから CMS ワークスペースへのランディングページのコピー
    ランディングページを今後のマーケティングキャンペーンで使用するには、CMS マーケティングワークスペースにコピーします。

Account Engagement ビジネスユニット間でのマーケティングアセットのコピー

マーケティングアセット (メールテンプレート、ファイル、カスタム項目、カスタムリダイレクトなど) を手動で再作成するのではなくビジネスユニット間で共有します。

必要なエディション

使用可能なエディション: Account Engagement Growth Edition、Plus Edition、Advanced Edition、Premium Edition
必要なユーザー権限
フローへのアクセス権を管理する フローの管理
フローを作成およびテストする フローの管理

開始する前にフロー Lightning コンポーネントをキャンペーンページに追加します。キャンペーンに必須のフローコンポーネントがない場合、「Lightning ページへのフローの追加」を参照してください。

また、マーケティングアセットの共有に必要なリモートサイトを有効化します。

  1. [設定] の [クイック検索] ボックスに「フロー」と入力します。
  2. [プロセスの自動化] で [フロー] を選択します。
  3. [Account Engagement Bulk Asset Copy Flow (Account Engagement 一括アセットコピーフロー)] をクリックします。
  4. Flow Builder で [実行] をクリックします。
  5. [ビジネスユニットを選択] で、マーケティングアセットのコピー元である [Source Business Unit (コピー元ビジネスユニット)] とマーケティングアセットの追加先である [Destination Business Unit (コピー先ビジネスユニット)] を選択して、[次へ] をクリックします。
    Sandbox ビジネスユニット間でコピーする場合は、まず [指定ログイン情報] を選択して [次へ] をクリックし、コピー元およびコピー先のビジネスユニットを選択します。
  6. ソースビジネスユニットからコピーするアセットを選択し、[次へ]をクリックします。
  7. コピーする必要があるアセットを選択したことを確認して、[次へ] をクリックします。
  8. [完了] をクリックします。

コピーしたマーケティングアセットを確認するには、コピー先ビジネスユニットに移動します。

Salesforce Content Builder で使用する Account Engagement マーケティングアセットを準備します。Account Engagement フォームとメールを CMS にコピーする前に、コピーする要素を確認します。

基本的な HTML を使用したシンプルなマーケティングアセットは、CMS へのコピーに適しています。Salesforce コンテンツビルダーでカスタム CSS、埋め込み画像、または差し込み項目を使用してマーケティングアセットを再構築することをお勧めします。

スパムフィルターを回避するためのベストプラクティス

一部のスパムフィルターでは、メッセージがスパムであるかどうかを判断するとき、メールの件名と本文テキストが評価されます。各自のメールでスパムフィルターがトリガーされないようにするベストプラクティスをいくつか紹介します。

必要なエディション

使用可能なエディション: すべての Account Engagement エディション

インタラクティブコンテンツを避ける

一部のインタラクティブコンテンツは、メールがスパムメールと認識される原因となることがあります。以下のものをメールコードに組み込むと、スパムフィルターがトリガーされることがあります。

  • JavaScript
  • RSS フィード
  • フォーム

コードをクリーンにする

Microsoft Word などのワードプロセッサから Account Engagement に HTML をコピーすると、スタイルタグやその他のコードが追加され、表示の問題が発生する可能性があります。HTML コンテンツをコピーする場合、まずメモ帳などのテキストエディターにコピーして、すべての書式設定を削除します。書式設定を再度追加するには、書式設定されていないテキストを Account Engagement のエディターにコピーします。

テキストに対する画像の比率を低く保つ

HTML メールのテキスト量と比較して、画像の数が多すぎたり、画像のサイズが大きすぎたりすると、メッセージがフィルターによってスパムと認識される可能性があります。この場合は、テキスト量を増やすか、画像の数またはサイズを減らしてください。

画像をデフォルトでブロックするメールクライアントもあるため、受信者に画像が自動的には表示されないことがあります。alt タグを組み込んで、画像が読み込まれない場合は画像の説明が表示されるようにしておきます。

リンクに気を付ける

短縮 URL をメールで使用することは避けます。スパム送信者は短縮 URL を悪用することが多いため、一部の短縮ドメインは、広く使用されているブロックリストに登録されています。多くのスパムフィルターは、短縮ドメインの短縮リンクを含むメールをブロックします。

ほとんどのスパムフィルターは、複数のドメインのリンクを含むメールをスパムとみなすため、メール内でリンクするドメインの数を制限してください。

住所およびオプトアウトする方法を組み込む

マーケティングメールには、送信者の住所、および受信者が今後メールを受信を望まない場合にオプトアウトする方法を記載する必要があります。登録解除やメールプリファレンスセンターのリンクまたは住所が記載されていないマーケティングメールは、スパムフィルターをトリガーすることがあります。ただし、メールテンプレートはフッターに登録解除リンクが組み込まれるため、この情報を追加することに注意を割く必要はありません。

ダイナミックコンテンツの使用に関する考慮事項

ダイナミックコンテンツを作成するときは、次の考慮事項を念頭に置いてください。

  • HTML メールのみで動的コンテンツがサポートされます。プレーンテキストのメールでダイナミックコンテンツを使用するには、メールのソースコード内でその HTML タグを手動で削除します。

メモ カテゴリを選択していないフォルダーにフォルダー権限を適用しないでください。アセットの作成時にユーザーがフォルダーを選択していない場合、アセットはカテゴリを選択していないフォルダーに配置されます。ユーザーにカテゴリを選択していないフォルダーにアクセスする権限がない場合、アセットにアクセスできなくなります。

フォルダー権限を適用するときは、次の考慮事項を念頭に置いてください。

  • 管理者はすべてのフォルダーにアクセスできます。
  • サブフォルダーは、親フォルダーから権限を継承します。たとえば、フォルダー 1 にフォルダー A とフォルダー B が含まれているとします。フォルダー 1 へのアクセス権を付与すると、フォルダー A とフォルダー B へのアクセス権も付与されます。必要に応じて、サブフォルダーの権限を明示的に設定できます。
  • サブフォルダーに設定された権限は、親フォルダーから継承された権限を上書きします。サブフォルダーに独自の権限と親フォルダーの権限を付与するには、サブフォルダーに両方の権限を設定します。
  • アクセス権のあるグループを選択するまでフォルダーは公開されたままになります。
  • プロスペクトはフォルダーに配置できないため、プロスペクトでフォルダー権限を使用することはできません。
  • Salesforce コネクタを使用している場合、リストの [CRM 参照可能] にチェックが入っていると、リストのフォルダー権限が Salesforce に引き継がれます。たとえば、営業ユーザーにリスト 1 と 2 を含むフォルダー A へのアクセス権がない場合、ユーザーが Salesforce のリストにプロスペクトを追加しても、リスト 1 と 2 は表示されません。
  1. [フォルダー] ページを開きます。
    • Account Engagement で、[マーケティング]、[フォルダー] の順に選択します。
    • Lightning アプリケーションで、[コンテンツ]、[フォルダー] の順に選択します。
  2. アクセスを制限するフォルダーを検索します。
  3. 歯車アイコンをクリックし、[権限] を選択します。
  4. フォルダーのコンテンツにアクセスできるグループを選択します。
  5. 完了したら保存します。

適用された権限のあるフォルダーの名前の横にロックアイコンが表示されます。

  • マーケティングアセットへのリンクのカスタマイズ

  • マーケティングアセットでの画像の使用
    画像をアップロードするか自分でホストして、マーケティングアセットで使用します。

スニペットに関する考慮事項

スニペットを使用するときは、次の考慮事項を念頭に置いてください。

必要なエディション

キャンペーンスニペットを使用可能なエディション: Salesforce Professional Edition、Enterprise Edition、Performance Edition、および Unlimited Edition (Account Engagement Edition 付属)
ビジネススニペットを使用可能なエディション: Salesforce Professional Edition、Enterprise Edition、Performance Edition、および Unlimited Edition (Account Engagement Growth Edition、Plus Edition、Advanced Edition、および Premium Edition)

開始する前に

  • スニペットは、Handlebars 差し込み言語 (HML) で入力されます。従来の差し込み言語を使用している場合は、開始する前に管理者がアカウントを HML にアップグレードしてください。
  • 接続されたキャンペーンが有効になっている必要があります。キャンペーンスニペットは接続済みキャンペーンに割り当てられた場合のみ機能します。
  • 組織全体のデフォルトが「公開参照・更新」にあらかじめ設定されていて、変更はできません。
  • スニペットは Salesforce に保存され、データストレージに含まれます。

スニペットの操作

  • スニペットの [名] 項目は差し込み項目ピッカーの表示ラベルとして表示されます。わかりやすい内容を選択してください。
  • スニペットを保存するためには、API 参照名が必要です。これは、スニペットコンテンツをアセットの HML タグに関連付けるために使用されるためです。エラーメッセージでは、この項目は Developer Name (API 参照名) と呼ばれます。
  • スニペットには各割り当てについて一意の API 参照名が必要です。たとえば、「event_date」という API 参照名のスニペットは複数保存できますが、キャンペーンまたはビジネスユニットごとに保存できるのは 1 つだけです。
  • スニペットは、複数のキャンペーンまたはビジネスユニットに関連付けることができます。複数の割り当てを持つスニペットは、すべての割り当てで同じ値を表示します。HML は、スニペットを含むアセットの関連キャンペーンまたはビジネスユニットに基づいて解決します。
  • ランディングページにフォームを埋め込むと、スニペットはフォームに割り当てられているキャンペーンまたはビジネスユニットを使用します。
  • スニペットでは HML 差し込み項目を使用できます。ダイナミックコンテンツはサポートされていません。
  • [保存] をクリックしてビジネススニペットを作成すると、一時的にビジネスユニットの表示ラベルがビジネスユニットの API 参照名に置き換えられます。これは、想定される動作です。

テスト、削除、制限

  • ユーザーがスニペットをキャンペーンに割り当てたり、キャンペーンの割り当てを表示したりできない場合は、ユーザーがキャンペーンに対する参照権限を持っていることを確認してください。
  • スニペットが含まれるメールは通常どおりに HTML およびプレーンテキストとして送信されます。ただし、プレーンテキストバージョンは編集できません。ハイパーリンクおよび画像はテキスト URL として表示され、テキストの書式設定は HTML タグとして表示されます。
  • Salesforce Engage メールでスニペットを使用できます。差し込み項目ピッカーにはスニペットは含まれていませんが、手動でスニペットを追加でき、Engage メールが送信されるとスニペットが正常に解決されます。
  • スニペットレコードを削除しても、アセットからは削除されません。残りのスニペットタグは空白として解決されます。
  • スニペットは、Salesforce または Account Engagement Sandbox ではサポートされません。
  • スニペットはダイナミックコンテンツまたはユーザー署名ではサポートされません。
  • スニペットはテストメール送信では正常に解決されません。
