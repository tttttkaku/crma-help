Agentforce for Scale

Use conversational AI to monitor org performance and analyze results directly in Scale Test, Scale Center, and ApexGuru.

Agentforce for Scale is an Agentforce agent built for the Salesforce Scalability suite. It centralizes performance insights and automates diagnostic workflows, letting you identify issues and act on them without leaving the product.

Main Topics

Org Performance Analysis
Retrieves org-wide performance metrics and generates diagnostic investigations, including Row Lock, Apex Summary, and Governor Limit analysis.
Live Scale Test Monitoring
Analyzes Requests Per Second (RPS) data and generates health reports for active scale test sessions.
Default Topic for Scale Products
Answers general questions about Scale Test, Scale Center, ApexGuru, and related functionality by using product documentation.

Considerations

  • Agentforce for Scale requires a Scale Center or Scale Test license, the PlatformAiAppDevAddOn SKU, and Salesforce Foundations with the Flex Credits Add-on SKU.
  • Deploy Agent for Setup before activating Agentforce for Scale. Agent for Setup enables the Agentforce button in performance-related setup pages.
  • Agentforce for Scale uses the Agentforce for Scale template configured with actions specific to Scale Test, Scale Center, and ApexGuru.

Set Up Agentforce for Scale

Configure and activate Agentforce for Scale to use AI-powered performance analysis in Scale Test, Scale Center, and ApexGuru.

Before setting up Agentforce for Scale, confirm that your org has:

  • A Scale Center or Scale Test license
  • The PlatformAiAppDevAddOn SKU, which includes the AgentforceScale org and user permissions
  • The Foundations add-on, which enables Agentforce Platform features
  1. Turn on Einstein.
    1. From Setup, in the Quick Find box, search for and select Einstein Setup.
    2. Set the Turn on Einstein toggle to On.
  2. Turn on Agentforce.
    1. From Setup, in the Quick Find box, search for and select Agentforce Agents.
    2. Set the global Agentforce toggle in the top-right corner to On.
  3. Assign the required permission set license and permission set to each user.
    1. From Setup, go to Users, then click Users.
    2. Select a user, then click Permission Set License Assignments and add Agentforce Platform Developer and Admin.
    3. For the same user, click Permission Sets and add Agentforce Developer and Admin Tools.
  4. Deploy Agent for Setup.

    Agent for Setup enables the Agentforce button on performance-related setup pages, including Scale Center and Scale Test.

    1. From the Agentforce Agents page, click New Agent.
    2. Select the Agent for Setup template and click Create.
    3. In Agentforce Builder, click Activate.
  5. Create and configure Agentforce for Scale.
    1. Return to the Agentforce Agents page and click New Agent.
    2. Select the Agentforce for Scale template and click Create.
    3. Define the agent's profile with these values:
      Field Value
      Name Agentforce for Scale
      API Name Agentforce_for_Scale
      Role Provide actionable recommendations and performance analysis using the Salesforce Scalability suite.
      Company Your company name
      Tone Casual
    4. Click Activate in the top-right corner of Agentforce Builder.

      If activation warnings appear, click Ignore and Activate to complete deployment.

  6. Manage employee agent access.

    To give users access to an Agentforce Employee agent created in Agentforce Builder, add the agent to a permission set or profile in Setup.

    1. From Setup, in the Quick Find box, enter Permission Sets, and then select Permission Sets. Or, enter Profiles, and then select Profiles.
    2. Select a permission set or profile.
    3. Edit the Enabled Agent Access settings.
    4. Select the Agentforce Employee agents that you want to give users access to, and then click Save.
