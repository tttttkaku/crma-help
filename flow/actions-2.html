レコードアクションをロック

ワークフロー対応または承認対応レコードを承認中に編集できるようにロックまたはロック解除し、ロック中のレコードを編集できるユーザーを指定します。

必要なエディション

サポートされているエディションを表示する。

Flow Builder で、[アクション] 要素をフローに追加します。[新規アクション] ウィンドウで、[レコードをロック] を検索し、[レコードをロック] を選択します。

入力値の設定

フローの前半の値を使用して、アクションの入力を設定します。

項目 説明
アクション

必須。レコードで実行されるアクションを指定します。有効な値は、次のとおりです。

  • Lock
  • Unlock
レコード ID

必須。ロックまたはロック解除するレコードの ID。
許可 ID 省略可能。ユーザー、グループ、キューの ID。または、ロック中のレコードを編集できるユーザーを表すユーザーロールレコード。

使用方法

このアクションは、API バージョン 61.0 以降で実行されているフローで使用できます。

レコードをロックするには、ユーザーまたはログイン情報の Experience Cloud サイト訪問者にレコードへの参照アクセス権が必要です。

ロックされたレコードを編集するには、許可されているユーザーまたはログイン情報のある Experience Cloud サイト訪問者にレコードへの編集アクセス権が必要ですが、システム管理者はいつでもロックされたレコードを編集できます。

[許可 ID] パラメーターでユーザーロールが指定されている場合、ロックされたレコードを編集するには、ロール階層内の指定されたユーザーロール以上のユーザーロールが必要です。

[許可 ID] パラメーターに指定するグループまたはキューは、ユーザーのグループまたはキューか、Experience Cloud サイト訪問者のグループまたはキューまたはログイン情報である必要があります。指定されたグループまたはキューには、次のものを含めることはできません。

  • ロール
  • ロール & 内部下位ロール。

すでにロックされているレコードをロックしようとすると、エラーコード UNABLE_TO_LOCK_RECORD でエラーが発生します。

システム管理者、レコードをロックしたユーザーまたはログイン情報のある Experience Cloud サイト訪問者、またはロックされたレコードで許可されているユーザーがレコードのロックを解除できます。他のユーザーが試行すると、INSUFFICIENT_ACCESS_OR_READ_ONLY エラーコードでエラーが発生します。

アクションがすでにロック解除されているレコードをロック解除しようとすると、アクションはエラーなしで完了します。

制限事項

このアクションでレコードがロックされ、そのレコードが従来の承認プロセスに送信されると、従来の承認プロセスでレコードのロックが上書きされます。

  • Classic 承認プロセスでこのアクションのロックが上書きされると、このアクションで指定された許可されたユーザーはレコードを編集できなくなります。
  • このアクションで従来の承認プロセスによってロックされたレコードがロック解除されると、従来の承認プロセスが中断される場合があります。

ページを開くアクション

画面フロー中にユーザーのブラウザーで Salesforce または外部ページを開きます。

必要なエディション

サポートされているエディションを表示する。

Flow Builder で、[アクション] 要素をフローに追加します。[新規アクション] ウィンドウで、[ページ] を検索し、[ページを開く] を選択します。

入力値の設定

フローの前半の値を使用して、アクションの入力を設定します。

入力値 説明
ページ種別

必須。開くページの種別。有効な値は、次のとおりです。

  • Salesforce Record Page
  • External Web Page

Salesforce レコードページ

ユーザーのブラウザー内で Salesforce レコードページを開くには、このオプションを選択します。このセクションの項目は、このオプションを選択した場合にのみ表示されます。

項目 説明
レコード ID

必須。開くレコードの ID。
オブジェクト名

必須。レコード ID のオブジェクトの API 参照名 (取引先、取引先責任者など)。
ビューモード

必須。ユーザーがページを表示モードで開くか編集モードで開くかを指定します。開いたページを編集する権限がユーザーにない場合は、表示モードで開きます。
ページを開く場所

必須。開くページの種別を指定します。

  • New Browser Tab
  • New Browser Window
  • New Lightning Console Tab

    このオプションでは、現在のブラウザ タブの新しい Lightning タブでページが開きます。現在のブラウザ タブに Lightning コンソールが表示されない場合は、代わりに新しいタブが開きます。

外部 Web ページ

ユーザーのブラウザー内で Salesforce レコードページを開くには、このオプションを選択します。このセクションの項目は、このオプションを選択した場合にのみ表示されます。

項目 説明
URL

必須。開くページの URL。
ページを開く場所

必須。開くページの種別を指定します。

  • New Browser Tab
  • New Browser Window

利用状況

このアクションは、API バージョン 67.0 以降で実行されているフローで使用できます。

グローバルまたはオブジェクト固有のアクション

組織ですでに設定されているオブジェクト固有のアクションまたはグローバルアクションをコールします。[作成]、[更新]、および [活動の記録] アクションのみを使用できます。

必要なエディション

サポートされているエディションを表示する。

Flow Builder で、[アクション] 要素をフローに追加します。[アクション] 項目で、設定するオブジェクト固有のアクションまたはグローバルアクションを選択します。

オブジェクト固有の各アクションの API 参照名には、関連付けられているオブジェクトのプレフィックスが付きます (例: quickAction-Task.UpdatePriority)。各グローバルアクションの API 参照名には、プレフィックスは付きません (例: quickAction-NewAccount)。

入力値の設定

フローの前半の値を使用して、アクションの入力を設定します。

項目 説明
関連レコード ID

オブジェクト固有のアクションのみ。アクションの実行元のレコードの ID。

たとえば、アクションで、特定の取引先に関連付けるケースを作成するとします。その取引先の ID を [関連レコード ID] に割り当てます。

このパラメーターでは、任意の種別の単一値リソースを使用できます。その値はテキストとして処理されます。
入力パラメーター

アクションごとに異なります。

アクションレイアウトによって必須パラメーターが決まります。必須パラメーターはデフォルトで表示され、削除できません。必須項目にデフォルト値または定義済みの値がある場合、その項目はフローのオブジェクト固有のアクションおよびグローバルアクションでは省略可能です。その項目のデフォルト値または定義済みの値を後で削除した場合、フローで値を設定していないと、実行時にインタビューが失敗します。

値はパラメーターと互換性がある必要があります。
例 組織には、取引先のケースレコードを作成するオブジェクト固有のアクションがあります。フローでは、実行時にそのアクションをコールし、フローの前半の値を使用して取引先 ID を識別します。
メモ 実行時、インタビューのトランザクションが完了するまで、レコードは作成または更新されません。インタビューが完了または実行されたときに、画面、ローカルアクション、または待機要素がトランザクションに反映されます。

Quip フローコアアクション

Quip には、フローで Quip コンテンツを整理、作成、コピーするためのコアアクションが用意されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[Quip] カテゴリを選択し、該当のアクションを検索します。

必要なエディション

使用可能なインターフェース: Lightning Experience
Quip でサポートされているエディションを表示します。
重要 Quip コアアクションでは、システム実行フローまたは自動化プロセスユーザーはサポートされません。Quipコア アクションは、コンテキスト ユーザーとも呼ばれるユーザーのコンテキストで実行されます。フローは、コンテキストユーザーがアクセス権を持つものすべてにアクセスできます。
  • Quip 文書を作成アクション
    文書、スプレッドシート、またはスライドデッキを作成して、コンテンツを追加します。
  • Create Quip Chat Action (Quip チャットアクションの作成)
    チャットルームを作成し、メンバーにメッセージを送信します。
  • Quip フォルダーの作成アクション
    非公開フォルダーを作成するか、または作成したフォルダーを既存のフォルダーに追加します。
  • [Quip 文書をコピー] アクション
    文書をコピーしてテンプレートとして使用します。コピーした文書は、デフォルトでは Quip の実行ユーザーの非公開フォルダーに追加されます。
  • Quip コンテンツをコピーアクション (廃止)
    コピー元のスライドデッキからコンテンツをコピーして、コピー先スライドに貼り付けます。
  • Live Paste アクションを使用してコピー
    Live Pasteを使用して、ソースQuip文書からコンテンツをコピーして新しい文書に貼り付けます。ソースコンテンツが更新されると、Live Paste でコンテンツを貼り付けた Quip 文書も更新されます。
  • Quip 文書をレコードに添付アクション
    Salesforce レコードに文書を添付します。リンクされた文書は、[Quip 関連文書] コンポーネントに表示されます。
  • Quip 文書を編集アクション
    文書、スプレッドシート、またはスライドのコンテンツを編集します。文書セクションに基づいてコンテンツを追加または置換します。
  • Quip 文書をロックアクション
    Quip 文書を完了としてマークするには、文書を編集できないようにロックします。
  • [Quip セクションをロック] アクション
    Quip 文書のセクションを完了としてマークしたり、誤って編集されないようにロックしたりします。
  • Quip 文書を PDF にエクスポートアクション
    Quip 文書を PDF にエクスポートして、完了としてマークし、レコードのコピーを保持します。エクスポートした PDF は、Quip 文書または Salesforce レコードに添付できます。
  • Quip チャットでメッセージを送信アクション
    Quip チャット ルームにメッセージを送信します。
  • ドキュメントアクションでメッセージを送信
    Quip 文書の会話ペインにメッセージを追加します。
  • Quip 文書をフォルダーに追加アクション
    文書をフォルダーに追加し、文書を整理して共有します。
  • 文書 Quip アクションへのメンバーの追加
    異なるアクセス権のユーザーを文書に追加します。
  • [メンバーを Quip チャットに追加] アクション
    チャットルームにユーザーを追加します。
  • フォルダーから Quip 文書を削除アクション
    フォルダーから Quip 文書を削除します。共有Quip文書を再度非公開にします。
  • Quip 文書からメンバーを削除アクション
    Quip 文書へのユーザーのアクセス権を削除します。
  • Quip チャットアクションからメンバーを削除
    Quip チャットルームからユーザーを削除します。

[メールを送信] アクションの使用

フローで [メールを送信] アクションを使用するには、「フローからのメールの送信」を参照してください。

トランザクションおよびメール送信可能性情報

実行時、インタビューのトランザクションが完了するまで、フローはメールを送信しません。インタビューが完了または実行されたときに、画面、ローカルアクション、または待機要素がトランザクションに反映されます。フローを有効化する前に、組織で [設定] | [送信] | [メールを送信するためのアクセス権 (すべてのメールサービス)] | [すべてのメール] でメールを送信できることを確認します。

  • [Email Deliverability (メールの送信)] を [アクセス権なし] に設定し、[メールテンプレート ID] または [送信時にメールを記録] 項目を設定していない場合、フローは実行されますが、メールは送信されません。
  • [Email Deliverability (メールの送信)] を [アクセス権なし] に設定し、[メールテンプレート ID] または [送信時にメールを記録] 項目を設定すると、メールの送信時にフローからエラーが返されます。

考慮事項

  • [メールを送信] アクションを使用して送信されたメールには、[私のメール設定] のメール署名は含まれません。署名を含めるには、メールテンプレート、フローテキストテンプレート、または [メールを送信] アクションで使用されるその他のリソースに署名を追加します。
  • 関連レコード ID がフローでケース ID として設定されている場合、カスタマーコミュニティユーザーは EmailMessage レコードを作成できません。詳細は、「Experience Cloud ユーザーライセンス」を参照してください。
  • ロールバックモードでフローをデバッグする場合、[メールを送信] アクションではメールが送信されません。
  • このフローでは、添付ファイルを含めて最大 35 MB のメールが作成されます。サイズが 35 MB を超えると、実行時にフローが失敗します。
  • API バージョン 64.0 以前を使用してフローをエクスポートするには、[メールを送信] アクションバージョンを 1.0.1 に変更します。
  • 受信者住所項目のバージョン変更エラーを修正するには、警告を削除してパラメーターを再入力します。
  • [メールを送信] アクションバージョン 2.0.1 以降を使用してフローをエクスポートするには、sfdx-project.json ファイルの sourceApiVersion 項目に API バージョン 65.0 以降を指定します。
  • 受信者メールアドレス項目に実行時に空の変数が含まれているか、受信者メールアドレスが無効なユーザーに属している場合、フローは「おそらく制限を超えました。または受信者が 0 人です」エラーを返します。解決策の詳細については、Knowledge Article: Error 'Probably Limit Exceeded or 0 recipients' in a Flow with a Send Email or Email Alert Action ([メールを送信] または [メールアラート] アクションを使用したフローでのエラー 'おそらく制限を超えました。受信者が 0 人になりました)を参照してください。

スケジュールトリガーフローでの [メールを送信] アクションの使用

スケジュール済みトリガーフローで [メールを送信] アクション要素を使用する場合は、[設定] で組織のメールアドレスを設定します。

  • [設定] | [メール] | [組織のメールアドレス] で組織のメールアドレスを設定します。
  • [設定] | [プロセスの自動化設定] | [自動化プロセスユーザーのメールアドレス] で組織のメールアドレスを追加します。

メール送信制限

  • [送信時にメールを記録] または [メールテンプレート ID] を使用している場合、1 日のメール送信制限は単一メールの制限に基づきます。「メールの全般的な制限」を参照してください。
  • [Log Email on Send or Email Template ID (送信時にメールを記録)] または [メールテンプレート ID] を使用しない場合、1 日のメール送信制限は 1 日のワークフローメール制限に基づきます。「Proactive Alert Monitoring: Daily Workflow Email Limit (プロアクティブアラート監視: 毎日のワークフローメールの制限)」を参照してください。
  • ライセンスのある各組織は 1 日あたり最大 5,000 件の外部メールアドレス (受信者) に単一メールを送信できます。1 日は、グリニッジ標準時 (GMT) に基づきます。
  • 内部メール受信者へのメールの送信は、この組織の日次制限には反映されません。

フロー移行中の ID の処理

フローで [メールを送信] アクションを設定する場合、一意のレコード ID を使用してメールテンプレートや添付ファイルなどのレコードを参照します。これらの ID は、作成された Salesforce 組織に固有です。

Sandbox から本番に移行する場合や異なる環境間でフローを移行する場合、これらのアセットのレコード ID が変更されます。その結果、[メールを送信] アクションでの元のメールテンプレートまたは添付ファイルレコード ID への参照は無効になります。

移行後、対象組織で新しく作成されたメールテンプレートまたは添付ファイル ID を参照するようにフローを手動で更新します。

重要 フローを移行したら、常に [メールを送信] アクションを確認して再設定し、対象 Salesforce Org の新しいレコード ID を参照します。このステップにより、参照の破損が回避され、移行後にメール配信が正しく機能するようになります。

メッセージの固定または固定解除

値または Boolean リソースを選択します。有効な値は、次のとおりです。

固定
メッセージを会話ヘッダーに固定します。
固定解除
メッセージを会話ヘッダーから固定解除します。

選択した Boolean 値が True に評価される場合、このアクションはメッセージを固定します。選択した Boolean 値が False に評価される場合、このアクションはメッセージを固定解除します。デフォルトは [固定] です。
