SurveyMonkey コネクタ

外部 SurveyMonkey アカウントに接続します。連絡先の同期やコレクターの作成などのタスクを実行します。SurveyMonkey をデータ対象 (アクション) として使用します。

必要なエディション

サポートされているエディションを表示する。
この機能を使用するには、MuleSoft for Flow: Integration アドオンが必要です。ただし、MuleSoft for Flow: Integration アドオンを必要としないセグメントトリガーフロー、有効化トリガーフロー、ブロードキャストフローは例外です。Professional Edition では、API アクセス Add-on/アドオンが必要です。アドオンを購入する場合は、Salesforce アカウントエグゼクティブにお問い合わせください。
MuleSoft for Flow: Agentforce で使用するインテグレーション機能には、Foundations Edition または Agentforce 1 Edition が必要です。これらのエディションを購入するには、Salesforce アカウントエグゼクティブにお問い合わせください。
メモ 接続はオートメーションアプリケーションでのみ編集または削除できます。

接続

標準接続または既存の外部指定ログイン情報を使用して、ソースまたはターゲットシステムに接続します。フロー内で複数のシステムに接続し、各接続を再利用できます。接続は、Integrations タブまたは Flow Builder で作成できます。

標準接続

このシステムはベアラー認証を使用します。

ベアラー認証では、各リクエストごとに、Authorizationヘッダーに Bearer という値とトークンが含まれて送信されます。

このシステムの接続には、次のログイン情報が必要です。

項目 説明
接続名

この接続の詳細を覚えやすい一意の接続名を入力します。接続を作成すると、Salesforce によってログイン情報が非表示になります。必要に応じて接続を再利用します。

「インテグレーション接続を管理」権限を持つユーザーは、組織内のすべての接続を表示および使用できます。
トークン

要求を認証するために使用するベアラートークンを入力します。ベアラートークンの作成方法についての詳細は、外部システムのマニュアルを参照してください。
URL

インスタンスの URL を入力します。

指定ログイン情報接続

[設定] から、外部システム接続に使用する既存の指定ログイン情報を選択します。

指定ログイン情報を使用して外部システムに接続する前に、既存の認証済み指定ログイン情報と、ユーザーに対して有効になっている外部ログイン情報を作成または使用します

フローで使用するための正常な接続を確保するには、指定ログイン情報ごとに 1 つのプリンシパルのみを使用します。

  • 指定ログイン情報とその関連オブジェクト (外部ログイン情報や外部認証 ID プロバイダーなど) には同じ名前を使用します。これらのオブジェクトの表示ラベルは異なる場合があります。
  • 接続を作成するユーザーにプリンシパルに必要なユーザー権限を割り当てます。この権限がないと、接続テストは失敗し、接続は無効のままになります。
重要

既存の指定ログイン情報との接続を作成する場合、次の点に注意してください。

  • [インテグレーション] タブではなく、[設定] で指定ログイン情報の参照のみの詳細を管理します。[インテグレーション] タブでは、接続の [接続名] と説明のみを編集できます。
  • [設定] で指定ログイン情報の再接続を実行します。[再接続] ボタンは [詳細] ページに表示されません。
  • [設定] で、関連付けられた指定ログイン情報を削除します。接続を削除しても、ログイン情報は削除されません。
重要 FIPS(連邦情報処理標準)標準に準拠するために、Government CloudではこのコネクタのOAuth 2.0認証はサポートされていません。代わりに、既存の指定ログイン情報を作成するか、認証に使用します。

アクション

アクションは、対象システム内で特定のタスクまたは操作を実行します。アクションを使用して、フローで設定された条件に基づいて、手動操作なしでさまざまなシステムのタスクを自動化します。アクションについての詳細は、「Create a Flow with a Connector as a Action (アクションとしてのコネクタを使用したフローの作成)」を参照してください。

Flow Builder では、次の SurveyMonkey アクションを使用できます。

  • Create Collector (コレクターを作成)
  • Create Collector Message (コレクターメッセージを作成)
  • Create Contact (取引先責任者を作成)
  • Create Contact List (取引先責任者リストを作成)
  • Creates A New Collector Recipient For A Message (メッセージの新規コレクター受信者の作成)
  • Delete Collector (コレクターを削除)
  • Delete Collector Message (コレクターメッセージを削除)
  • Delete Contact (取引先責任者を削除)
  • Delete Contact List (取引先責任者リストを削除)
  • Get Collector By ID (ID 別にコレクターを取得)
  • Get Collector Message By ID (ID 別にコレクターメッセージを取得)
  • Get Collector Recipients On A Message (メッセージのコレクター受信者を取得)
  • Get Contact By ID (ID 別に取引先責任者を取得)
  • Get Contact List By ID (ID 別に取引先責任者リストを取得)
  • Get Contacts In List (リストで取引先責任者を取得)
  • Send Message To Collector Recipients (コレクター受信者へメッセージを送信)
  • Update Collector (コレクターを更新)
  • Update Collector Message (コレクターメッセージを更新)
  • Update Contact (取引先責任者を更新)
  • Update Contact List (取引先責任者リストを更新)
ヒント API についての詳細は、外部システムの API ドキュメントを参照してください。
重要

接続およびサードパーティコネクタの具体的な制限については、「MuleSoft for Flow: Integration Limits & Considerations (フローの MuuleSoft: インテグレーションの制限と考慮事項)」を参照してください。

接続

標準接続または既存の外部指定ログイン情報を使用して、ソースまたはターゲットシステムに接続します。フロー内で複数のシステムに接続し、各接続を再利用できます。接続は、[インテグレーション] タブまたは Flow Builder で作成できます。

標準接続

このシステムはベアラー認証を使用します。

ベアラー認証では、要求ごとに [Bearer (ベアラー)] の値とトークンを含む Authorization という名前のヘッダーが送信されます。

このシステムの接続には、次のログイン情報が必要です。

項目 説明
接続名

この接続の詳細を覚えやすい一意の接続名を入力します。接続を作成すると、Salesforce によってログイン情報が非表示になります。必要に応じて接続を再利用します。

「インテグレーション接続を管理」権限を持つユーザーは、組織内のすべての接続を表示および使用できます。
トークン

要求を認証するために使用するベアラートークンを入力します。ベアラートークンの作成方法についての詳細は、外部システムのマニュアルを参照してください。
URL

インスタンスの URL を入力します。

指定ログイン情報接続

[設定] から、外部システム接続に使用する既存の指定ログイン情報を選択します。

指定ログイン情報を使用して外部システムに接続する前に、既存の認証済み指定ログイン情報と、ユーザーに対して有効になっている外部ログイン情報を作成または使用します

フローで使用するための正常な接続を確保するには、指定ログイン情報ごとに 1 つのプリンシパルのみを使用します。

  • 指定ログイン情報とその関連オブジェクト (外部ログイン情報や外部認証 ID プロバイダーなど) には同じ名前を使用します。これらのオブジェクトの表示ラベルは異なる場合があります。
  • 接続を作成するユーザーにプリンシパルに必要なユーザー権限を割り当てます。この権限がないと、接続テストは失敗し、接続は無効のままになります。
重要

既存の指定ログイン情報との接続を作成する場合、次の点に注意してください。

  • [インテグレーション] タブではなく、[設定] で指定ログイン情報の参照のみの詳細を管理します。[インテグレーション] タブでは、接続の [接続名] と説明のみを編集できます。
  • [設定] で指定ログイン情報の再接続を実行します。[再接続] ボタンは [詳細] ページに表示されません。
  • [設定] で、関連付けられた指定ログイン情報を削除します。接続を削除しても、ログイン情報は削除されません。
重要 FIPS(連邦情報処理標準)標準に準拠するために、Government CloudではこのコネクタのOAuth 2.0認証はサポートされていません。代わりに、既存の指定ログイン情報を作成するか、認証に使用します。

アクション

アクションは、対象システム内で特定のタスクまたは操作を実行します。アクションを使用して、フローで設定された条件に基づいて、手動操作なしでさまざまなシステムのタスクを自動化します。アクションについての詳細は、「Create a Flow with a Connector as a Action (アクションとしてのコネクタを使用したフローの作成)」を参照してください。

Flow Builder では、次の Zuva DocAI アクションを使用できます。

  • GET /extractions/
  • GET /extraction/{field_extraction_request_id}
  • GET /extraction/{field_extraction_request_id}/results/text
  • GET /fields
  • GET /fields/{training_field_id}/accuracy
  • GET /fields/{training_field_id}/train/{field_training_request_id}
  • GET /fields/{training_field_id}/validation-details
  • GET /mlcs
  • GET /ocrs
  • GET /ocr/{ocr_request_id}/text
ヒント API についての詳細は、外部システムの API ドキュメントを参照してください。
