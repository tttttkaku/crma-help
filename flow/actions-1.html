見積と商談の同期

このアクションにより、見積品目が商談品目に同期されます。このアクションは、API バージョン 68.0 以降で実行中のフローで入手可能です。

必要なエディション

使用可能なインターフェース: Lightning Experience
サポートされているエディションを表示する。

Flow Builder で、[アクション] 要素をフローに追加します。アクションを検索する項目に「Sync Quote to Opportunity」 (見積を商談に同期) と入力し、[Sync Quote to Opportunity] を選択します。

入力値の設定

項目 説明
見積 ID

必須。商談と同期する見積レコードの ID。見積 ID は 1 つだけ指定します。

出力値の保存

項目 説明
非同期操作トラッカー ID

同期プロセスを監視するための非同期操作トラッカー ID。

必要なエディション

使用可能なインターフェース: Lightning Experience
サポートされているエディションを表示する。

入力値の設定

フローの前半の値を使用して、アクションの入力を設定します。

項目 説明
ミーティング要求 ID 必須。生成された時間枠要請に関連付けられたミーティング要請の ID。
ミーティング時間 必須。選択した開始時刻に対応するエポックミリ秒単位のミーティング時間。

出力値の保存

項目 説明
エラーコード [セールスミーティングを確認] アクションによって返されるエラーコード。
Error Message [セールスミーティングを確認] アクションによって返されるエラーメッセージ。
ミーティング状況 ミーティングのスケジュール試行の状況。

ドキュメントアクションからのデータの抽出

AI を駆使した分析を使用してドキュメントから構造化データを抽出し、必要に応じてフローを続行する前に人間によるレビューを行います。

Flow Builder で、[アクション] 要素をフローに追加します。アクションを検索するフィールドに「Extract Data from Document」 (ドキュメントからデータを抽出) と入力し、[Extract Data from Document (ドキュメントからデータを抽出)] を選択します。

入力値の設定

フローの前半の値を使用して、[ドキュメントからデータを抽出] アクションの入力を設定します。

入力パラメーター 説明
コンテンツドキュメント ID 分析するコンテンツドキュメントレコードの ID。
ドキュメント処理設定 ID ドキュメントからデータを取得するために使用するドキュメント処理設定の API 参照名。

ヒューマンレビュー設定の定義

[ヒューマンレビュー設定] セクションを使用して、フローを続行する前に抽出されたデータを検証または修正します。レビューが必要な場合、レビュー担当者がレビューを送信または却下するまでフローは一時停止します。

Human Review Settings では、組織で Data 360 がプロビジョニングされ、有効になっている必要があります。

入力パラメーター 説明
抽出されたデータを人間が確認できるようにする

レビュー ToDo が作成されるタイミングを決定します。有効な値は、次のとおりです。

  • なし — 確認をスキップして、抽出されたデータを直接返します。この値がデフォルトです。
  • 必要な場合のみ — 1 つ以上のフィールドが信頼性しきい値を下回る抽出に対してのみレビュー ToDo を作成します。
  • 常に — 信頼性スコアに関係なく、抽出ごとにレビュー ToDo を作成します。
割り当て先 ToDo を確認するユーザー。

出力値の保存

抽出されたデータをフローの後半で使用するには、変数に保存します。この値は、ドキュメントが処理されるときに割り当てられます。

出力パラメーター 説明
コンテンツドキュメント ID 処理されたコンテンツドキュメントの ID。この値は、入力コンテンツドキュメント ID を返します。
ドキュメント処理設定 ID ドキュメントの処理に使用される IDP 設定の ID。
抽出されたデータ ドキュメントから抽出されたデータを含む Apex クラス。クラス名は IDP 設定によって決まります。
抽出されたデータ JSON ドキュメントから抽出されたデータの JSON 文字列表現。この出力には、抽出の信頼性スコアがドキュメント処理設定でそのフィールドに対して設定された信頼性しきい値を下回ったかどうかを示す挿入されたneedsManualReviewフラグが含まれます。

ヒューマンレビューのしくみ

レビュー ToDo が作成されると、フローは一時停止します。レビュー担当者はオートメーションアプリケーションの [ヒューマンレビュー] タブでレビューを完了します。レビュー担当者が ToDo を送信または却下すると、フローは検証または修正されたデータで再開され、却下された場合は障害パスに従います。

AI エージェントアクション

指定されたユーザーメッセージの AI エージェント応答を作成します。エージェントが有効になっている必要があります。

必要なエディション

使用可能なインターフェース: Lightning Experience
使用可能なエディション: Enterprise Edition、Performance Edition、Unlimited Edition、および Developer Edition。必要なアドオンライセンスはエージェント種別によって異なります。
統合機能のライセンスを表示します。

Flow Builder で、[エージェントを実行] 要素をフローに追加します。「AI Agent Actions」カテゴリを選択します。次に、回答を作成するエージェントの名前を選択します。

メモ API バージョン 67.0 以降、AI エージェントアクションはアクション要素から使用できなくなりました。エージェントを操作するには、[エージェントを実行] 要素を使用します。AI エージェントアクションを参照するアクション要素を含むフローを開くと、自動的に [エージェントを実行] 要素として表示されます。元の設定が保持されます。

各アクションの API 参照名には、generateAIAgentResponse が付与されます。

入力値の設定

入力パラメーター 説明
エージェント要求 このアクションの出力を生成するエージェントに送信する質問または要求。この項目は、バージョン 1.1.0 以降で使用できます。
ユーザーメッセージ このアクションの出力を生成するエージェントに送信する質問または要求。この項目は、バージョン 1.0.0 以前で使用できます。
セッション ID エージェントの応答を送信する会話セッションの ID。

構造化出力の設定

構造化出力を設定するには、アクションバージョン 1.1.0 以降を使用します。

項目 説明
項目名 必須。構造化出力項目の一意の英数字名。名前に特殊文字やスペースを含めることはできません。
説明 大規模言語モデル (LLM) の精度を高めるために項目名で使用する簡単な説明。
データ型

必須。項目のデータ型。有効な値は次のとおりです。

  • 文字列
  • 数値
  • Boolean
必須 LLM がこの出力項目の応答を生成する必要があることを示します。出力行を要求すると、LLM によって不正確または有害な応答が返される可能性があります。

出力値の保存

項目 説明
エージェントの回答 エージェントからの構造化されていない応答。構造化出力が設定されている場合は、nullを返します。
セッション ID エージェント応答がある会話セッションの ID。
構造化されたエージェント応答 エージェントからの構造化された出力。構造化出力が設定されていない場合は、nullを返します。この項目は、バージョン 1.1.0 以降で使用できます。

使用方法

このアクションは、次の条件を満たす場合にのみ使用できます。それ以外の場合、アクションは失敗します。

  • Agentforce が有効になっている。
  • フローを実行するユーザーに「AI エージェントの管理」権限があります。
  • 指定されたエージェントに有効なバージョンがあります。

選択したカスタムエージェントアクションに固有の入力は、[構造化出力を設定] セクションの後にリストされます。

構造化された出力の利用状況

構造化出力を設定する前に、[エージェントを実行] 要素で生成された表示ラベルを確認します。必要に応じて手動で編集し、フローを保存します。API 参照名は表示ラベルに基づいて入力されます。

構造化出力を設定する場合、保存する前に少なくとも 1 つの構造化出力項目を定義します。

カスタムエージェントアクションで構造化出力が設定されている場合、[現在の構造化出力] には関連付けられた構造化データ型が表示されます。

定義された構造化出力項目ごとに、定義された名前の項目と関連する Boolean _set 項目の 2 つの項目が作成されます。たとえば、「summary」という名前の構造化出力フィールドを定義した場合、「summary_set」という名前の Boolean フィールドも作成されます。

変数値 説明
True この項目は構造化されたエージェント応答に含まれていましたが、設定されていませんでした。
False 項目が構造化されたエージェント応答に含まれていなかった。

定義された構造化出力でnullが返される場合、フローの後半で関連する _set 項目を使用して、その項目がnullである理由を判断します。

ワークフローのフロートリガーの定義 (パイロット)

ワークフロールールからフローを起動できるようにフロートリガーを作成します。フロートリガーを使用して、複雑なビジネスプロセスを自動化できます。ロジックを実行するフローを作成し、イベントからワークフロールール経由でこのフローをトリガーするようにします。コードを記述する必要はありません。たとえば、ケースに関連するエンタイトルメントを検索して割り当てるフローがあります。ケースの作成時には常にこのフローを起動するフロートリガーを作成します。これにより、すべての新しいケースにデフォルトのエンタイトルメントが自動的に設定されます。

必要なエディション

使用可能なインターフェース: Salesforce Classic
使用可能なエディション: Enterprise Edition、Performance Edition、Unlimited Edition、および Developer Edition
必要なユーザー権限
ワークフロールールおよびアクションを表示する 「設定・定義の参照」
ワークフロールールとアクションを作成または変更する 「アプリケーションのカスタマイズ」
メモ フロートリガーワークフローアクションのパイロットプログラムは終了します。組織でパイロットをすでに有効にしている場合は、引き続きフロートリガーワークフローアクションを作成および編集できます。組織でパイロット機能を有効にしなかった場合は、Flow Builder を使用してレコードトリガーフローを作成するか、プロセスビルダーを使用してプロセスからフローを起動します。

フロートリガーの使用を開始するには、[設定] から [クイック検索] ボックスに「フロートリガー」と入力し、[フロートリガー] を選択します。作業を開始する前に

  4. フロートリガーを設定します。
    項目 説明
    名前 フロートリガーの名前。
    一意の名前 API でこのコンポーネントを参照する一意の名前を入力します。[一意の名前] 項目には、アンダースコアと英数字のみを使用できます。選択したオブジェクト内で一意であること、最初は文字であること、スペースは使用しない、最後にアンダースコアを使用しない、2 つ続けてアンダースコアを使用しないという制約があります。
    保護コンポーネント 将来の使用のために予約されています。

    [別の値を設定] をクリックして、最大値以内の値を設定します。

    名前

    入力アクセスを許可されている変数のみを選択できます。
    値

    フロー変数の場合、次のような操作が可能です。

    • リテラル値を入力する。
    • をクリックして項目を選択し、[挿入] をクリックする。

    • ワークフロールールを起動するように作成または編集されたレコードの現在の値を使用するには、「{!this}」と入力します。
    • ワークフロールールを起動するように編集されたレコードの直近の値を使用するには、「{!old}」と入力します。

操作手順

このアクションでは、本ユーザ、取引先責任者、リードのリスト、および取引先と商談を入力として使用します。これらの関連レコードに関する情報が EmailMessage レコードに保存されます。このアクションでは、一時的なメール ID と取引先責任者、ユーザー、リードを使用して、EmailMessage の CcIds、FromId、および ToIds 項目を更新します。取引先または商談レコードを使用して EmailMessage の RelatedToId フィールドを更新します。

このアクションで EmailMessage の CcIds、FromId、および ToIds フィールドを更新すると、EmailMessageRelation レコードが自動的に更新されます。同様に、ToDo レコードの AccountId 項目と RelationId 項目も自動的に更新されます。

指定されたプロンプトテンプレートと入力の大規模言語モデル (LLM) 応答に基づいて応答を作成します。

必要なエディション

使用可能なインターフェース: Lightning Experience
サポートされているエディションを表示する。

Flow Builder で、[アクション] 要素をフローに追加します。[新規アクション] ウィンドウで、[プロンプトテンプレート] または [プロンプトテンプレート (バッチ生成)] カテゴリを選択し、使用するプロンプトテンプレートの名前を選択します。個人生成では、完了した結果を 1 つずつ返しますが、一括生成では、LLM レート制限に達しないように、結果を返す前にすべての要求を完了します。バッチ生成では、1 日あたり 10,000 世代がサポートされます。モデルで一括処理がサポートされている場合、代わりに 1 日あたり 50,000 件が制限されます。プロンプトビルダーの [モデル] ドロップダウンの [制限] で [バッチサポート: はい] を探します。実際の完了までの時間はモデルプロバイダーによって異なり、異なる場合があります。

[一括生成] アクションには、[完了] と [タイムアウト] の 2 つのパスがあります。生成された応答を使用するには、要素を Completed パスに追加します。タイムアウトパスに要素を追加して、エラーと中断を記録します。[タイムアウトの長さ] は 1 日に設定する必要があります。[プロンプトテンプレート (バッチ生成)] アクションをクリックして、必要に応じて [タイムアウトを設定] の長さを更新します。開始後、ジョブは 2 時間以内に開始されます。

各アクションの API 参照名には、generatePromptResponse または generatePromptResponseBatch というプレフィックスが付きます。

入力値の設定

入力値は、プロンプトテンプレートに指定された入力変数に基づきます。

  • 一括処理生成ジョブは、このユーザーのコンテキストで実行されるため、一括処理生成ジョブを実行する前に、[設定]> [Process Automation Settings]> [Process Automation Settings] でデフォルトのワークフローユーザーを設定します。詳細は、「プロセスの自動化設定」を参照してください。

使用方法

[評価応答サマリーを取得] では、フローを使用して、Docgen を使用したサーバー側のドキュメント生成を簡単にトリガーできます。この呼び出し可能なアクションを使用して、調査のサマリーデータを下流のプロセスに渡すことができます。この呼び出し可能なアクションは、ドキュメントを生成するために Docgen ワークフローで使用できるサマリー JSON を提供します。

[調査応答サマリーを取得] 呼び出し可能アクションは、調査 ID を入力として使用し、OmniProcess ID を取得します。この ID は OmniProcess 要素を取得するために使用されます。また、調査 ID では、調査応答を取得し、応答を OmniProcess 要素とマージして、JSON 形式で調査サマリー応答が作成されます。

DocGen の制限事項

OmniScript では、同じ OmniScript 形式の変更履歴 (質問の追加や削除など) は提供されません。調査を送信するときにドキュメント生成をトリガーすることをお勧めします。サマリー API は、OmniScript の有効なバージョンからレイアウトデータを取得します。

DocGen には次の制限があります。

  • トークンデータは 131,072 文字までに制限されます。
  • サーバー側のドキュメント生成 - サポートされるドキュメントの最大サイズは 1 MB です。
  • クライアント側のドキュメント生成 - サポートされるドキュメントの最大サイズは 10 MB です。
  • サーバー側のドキュメント生成には、画像の種類のサポートはありません。画像の種類は、クライアント側のみでサポートされます。

    提供されたコンテキストに基づいて AI で生成されたおすすめを取得し、AI で生成されたアクション項目としておすすめを保存します。このアクションは、Agentforce Pipeline Management の一部として Get AI Recommendations from Call Transcripts フローで使用されます。
  • 対応可能なミーティング時間を取得アクション
    レコード所有者のスケジュールに基づいて、指定されたリード、取引先責任者、または個人取引先の対応可能なミーティング時間を取得します。このアクションを使用するには Inbox が必要です。このアクションは、API バージョン 66.0 以降を実行しているフローで使用できます。
  • 「コンテンツのメモを取得」アクション
    指定したレコードの最新のコンテンツノートデータを取得します。このアクションは、API バージョン 64.0 以降を実行しているフローで使用できます。
  • 会話インテリジェンスを取得アクション
    インサイトや会話の概要など、音声通話やビデオ通話に関するインテリジェンス情報を取得します。
  • 会話トランスクリプトアクションを取得
    指定された音声通話またはビデオ通話レコードの会話トランスクリプトを取得します。
  • Get Forecast Context Action (売上予測コンテキストを取得アクション)
    特定のユーザーの販売予測コンテキストを取得します。[売上予測ガイダンスを取得] 標準エージェントアクションの一部として売上予測ガイダンスフローで使用されます。
  • Get Forecast Opportunities Action (売上予測商談アクションを取得)
    指定した条件に一致するユーザーの販売予測商談を取得します。Get Forecast Guidance 標準エージェントアクションの一部として、売上予測ガイダンスフローで使用されます。 
  • 項目自動更新の提案アクションの取得または実行
    項目生成プロンプトテンプレートから項目更新の提案を取得する要求をキューに追加するか、生成された提案に基づいて項目を更新する (エージェントが自律的に更新するように設定されている場合)。このアクションは、Agentforce Pipeline Management の一部として Process Field Update Suggestions フローで使用されます。
  • Get Opportunity Content Note Action (商談コンテンツメモアクションを取得)
    指定された商談レコードの最新のコンテンツノートデータを取得します。このアクションは、Agentforce Pipeline Management の一部として Get Opportunity Grounding Data フローで使用されます。
  • Get Opportunity Stage Details (商談フェーズの詳細を取得) アクション
    指定された商談レコードに関連付けられたフェーズの名前と説明を取得します。このアクションは、Agentforce Pipeline Management の一部として Get Opportunity Grounding Data フローで使用されます。
  • [レコード優先度データを取得] アクション
    レコードデータと項目メタデータを取得して、ユーザーのレコードに優先度を付けます。このアクションは、[商談の詳細を取得] フローで [商談の優先度を設定] 標準エージェントアクションの一部として使用されます。
  • [関連メールを取得] アクション
    特定のレコードに関連し、指定された日付範囲内に記録されたメールのリストを取得します。このアクションは、API バージョン 66.0 以降を実行しているフローで使用できます。
  • ID ユーザー登録フローコアアクション
    これらのアクションは、ユーザーがシングルサインオン (SSO) でログインしたときに起動する認証プロバイダのユーザー登録フローで使用します。
  • レコードアクションをロック
    ワークフロー対応または承認対応レコードを承認中に編集できるようにロックまたはロック解除し、ロック中のレコードを編集できるユーザーを指定します。
  • ページを開くアクション
    画面フロー中にユーザーのブラウザーで Salesforce または外部ページを開きます。
  • [Chatter に投稿] アクション
    このアクションは、Chatter グループやケースレコードなど、指定されたフィードにメッセージを投稿します。メッセージにメンションやトピックを含めることはできますが、テキスト投稿しかサポートされていません。
  • フローコアアクション: プロンプトテンプレートアクション
    指定されたプロンプトテンプレートと入力の大規模言語モデル (LLM) 応答に基づいて応答を作成します。
  • グローバルまたはオブジェクト固有のアクション
    組織ですでに設定されているオブジェクト固有のアクションまたはグローバルアクションをコールします。[作成]、[更新]、および [活動の記録] アクションのみを使用できます。
  • Data Cloud での一括処理データ変換の実行アクション
    Data 360 (旧 Data Cloud) で一括処理データ変換を実行します。
  • Quip フローコアアクション
    Quip には、フローで Quip コンテンツを整理、作成、コピーするためのコアアクションが用意されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[Quip] カテゴリを選択し、該当のアクションを検索します。
  • B2B Commerce チェックアウトフローコアアクション
    B2B Commerce チェックアウトフローには、Commerce 組織内でチェックアウトプロセスを正常に実装するためのいくつかのコアアクションが用意されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[B2B Commerce] カテゴリを選択し、該当のアクションを検索します。
  • Commerce チェックアウトフローコアアクション
    Commerce チェックアウトフローには、Commerce 組織内でチェックアウトプロセスを正常に実装するためのいくつかのコアアクションが用意されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[Commerce] カテゴリを選択し、該当のアクションを検索します。カートアクションは、Aura テンプレート上に構築された B2B ストアのフローでは使用できません。
  • Salesforce 注文管理のフローコアアクション
    Salesforce 注文管理では、フローに注文管理機能を実装するためのいくつかのコアアクションが提供されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[注文管理] カテゴリを選択し、該当のアクションを検索します。
  • Salesforce オムニチャネル在庫フローコアアクション
    Salesforce オムニチャネル在庫では、フローに在庫機能を実装するためのいくつかのコアアクションが提供されています。これらのアクションのいずれかをフローに追加するには、[アクション] 要素を追加します。次に、[オムニチャネル在庫サービス] カテゴリを選択し、該当のアクションを検索します。
  • [会話メッセージを送信] アクション
    拡張メッセージングチャネルまたは拡張アプリ内チャットでメッセージングコンポーネントを 1 人以上のメッセージングユーザーに送信します。
  • カスタム通知の送信アクション
    特定のイベントが発生したときにカスタム通知をユーザーに送信します。カスタム通知は通知ベルに表示され、Salesforce デスクトップまたはモバイルアプリケーションに配信できます。
  • [メールを送信] アクション
    Flow Builder の [メールを送信] アクションを使用して、個々の受信者へのメールの送信、メールテンプレートの適用、添付ファイルの追加、必要に応じて関連レコードの活動タイムラインへのメールの記録を行います。利用者セグメントへの一括メール送信の場合は、代わりに [メールメッセージを送信] 要素を使用します。
  • 通知の送信アクション
    送信する通知種別を呼び出します。各 [通知の送信] アクションは、サポートされる通知種別に対応します。[通知の送信] アクションは、Slack 対応のカスタム通知種別と特定の Slack 対応の標準通知種別でのみ使用できます。
  • Slack アクションでの営業管理エージェント通知の送信
    営業管理エージェントから Slack のユーザーに通知を送信します。このアクションは、API バージョン 65.0 以降を実行しているフローで使用できます。
  • [アンケートを送信] アクション
    フローで名前、件名、受信者、招待リンクオプションを指定して、有効なアンケートを送信するアクションを作成します。
  • トーストメッセージアクションを表示
    ユーザーのページに簡単なメッセージウィンドウを表示します。メッセージには、外部コンテンツへのリンクを含めることができます。
  • アンケートセンチメント分析アクションの実行
    アンケートの回答の基盤となるセンチメントに関するインサイトを取得します。
  • Get Assessment Response Summary Action (調査への回答の概要を取得アクション)
    実行した調査の印刷用サマリービューを作成します。このアクションを使用すると、調査に保存された応答を抽出し、ドキュメントを生成するフローを作成できます。
  • [承認申請] アクション
    Classic 承認プロセスを使用して 1 つの Salesforce レコードの承認を申請します。このアクションでは、フロー承認プロセスを使用してレコードの承認は送信されません。
  • Slack フローコアアクション
    Slack チャンネル、チャンネルメンバー、メッセージをフローから管理します。Salesforce レコードが変更された場合に、フローによって Slack の変更をトリガーできます。
  • Slack の従来のアクション
    従来の Slack アクションは、Slack チャンネル、メンバー、メッセージを管理する古い方法に基づいています。
  • 見積と商談の同期
    このアクションにより、見積品目が商談品目に同期されます。このアクションは、API バージョン 68.0 以降で実行中のフローで入手可能です。
