B2C Commerce Einstein Product Recommendations

Einstein Product Recommendations を使用して Recommender を作成および管理し、個々の買い物客にとって最も関連性の高い商品を予測する戦略を割り当てます。このトピックは、B2C Commerce に該当します。

  • B2C Commerce Einstein Product Recommendations の実装
    B2C Commerce Einstein Product Recommendations を実装するには、さまざまなコンポーネントの構成、実行、および変更が必要です。これらの各タスクは、さまざまな役割が実行されます。このトピックは、B2C Commerce に該当します。
  • B2C Commerce Einstein Recommender
    B2C Commerce Einstein には、特定のページに配置できるさまざまなタイプの商品推奨があります。このトピックは、B2C Commerce に該当します。
  • B2C Commerce Einstein Recommender の戦略
    使用する予定の Recommender を決定したら、推奨戦略を指定します。このトピックは、B2C Commerce に該当します。
  • B2C Commerce Einstein Recommender および利用可能な戦略
    どの戦略を利用できるかは、使用したい Recommender のタイプに応じて異なります。このトピックは、B2C Commerce に該当します。
  • B2C Commerce Einstein Recommender のルール
    ルールでは、推奨商品 ID のリストを、ランタイム時にストアフロントに渡す前に調整することができます。各ルールには、アクション、フィールド、および 1 つまたは複数のフィールド値 (属性) が含まれます。このトピックは、B2C Commerce に該当します。
  • Product Recommendations の B2C Commerce Einstein Recommender の構成
    商品の Recommender を作成する場合は、使用する推奨タイプと戦略を指定します。また、ルールを追加して推奨項目を調整することもできます。
  • B2C Commerce Einstein での Recommender 出力のプレビュー
    Recommender を追加または変更した後、Recommender の出力をプレビューして、推奨項目のリストが最終的に買い物客にどのように表示されるかを確認します。
  • B2C Commerce Einstein での「セットを完成」カテゴリの管理
    セットのレビュータブを使用して、すべての Einstein の「セットを完成」カテゴリを個々に管理、または一括有効化または無効化の機能を使用して管理します。
  • B2C Commerce Einstein での Product Recommendations のコンテンツスロットの設定
    コンテンツスロットを使用して、ストアフロントで Product Recommendations を表示します。このトピックは、B2C Commerce に該当します。

B2C Commerce Einstein での Validator の応答

B2C Commerce Einstein 機能を使用しているサイトに移動すると、Validator によって推奨アクティビティと並べ替えルールがただちに検証されます。その後、検出されたアクティビティに基づいて、特定の応答が提供されます。このトピックは、B2C Commerce に該当します。

ストアフロントを Recommendation Validator でテストし、予想通りの動作を確認することをお勧めします。Validator がイベントを認識すると、検出されたイベントの数とともにアイコンが表示されます。

メモ Einstein と Page Designer を併用する場合は、コードが最新であることを確認してください。この GitHub リポジトリを参照してください。

ヒント: B2C Commerce リポジトリにアクセスする方法については、Salesforce B2C Commerce GitHub リポジトリおよびアクセスを参照してください。

明示的な推奨

推奨のソース と推奨のターゲット 間で明示的な関係を作成します。このトピックは、B2C Commerce に該当します。

明示的な推奨は、サイトで商品の推奨を有効にする 1 つの方法です。これらの推奨では、推奨のソース (カテゴリ、商品、または商品セット) を推奨のターゲット (商品または商品セット) に明示的にリンクする必要があるため、「明示的」な推奨と呼ばれます。

明示的な推奨は、Business Manager で手動で構成します。ただし、管理者はインポートフィードを作成して、サイトの多数の推奨を 1 つのジョブの実行で入力することも可能です。

明示的な推奨はクロスセリング (関連商品を推奨) またはアップセリング (より高額な商品を推奨) と呼ばれます。ただし、推奨項目をより詳細に定義することもできます。たとえば、ファミリー向け商品、無料商品または付属商品、競合商品など、複数のタイプのクロスセリングを実装します。このような商品は、ストアフロントで新着、こちらもお勧め、こちらもどうぞ、および売れ筋 といったラベルの下に表示できます。また、これらはホームページやカテゴリ表示ページ、商品詳細ページ、買い物カゴなど、ストアフロントのさまざまなセクションに表示できます。

明示的な推奨とは、Salesforce B2C Commerce 内のある商品から別の商品へのリンクです。最初の商品、すなわちソース には商品またはカテゴリを使用できます。もう一方の商品はターゲット と呼ばれます。このリンクには拡張可能なタイプ (例: クロスセリング、アップセリング) もあります。これらのタイプはストアフロントアプリケーションで使用して、推奨タイプを特定できます。

明示的な推奨にはカタログ範囲があり、カタログオブジェクト間、特定カテゴリ間、商品間で入力されたリンクを表します。明示的な推奨はこのようなカタログ要素に関連付けられていますが、それぞれ独立しています。明示的な推奨の並べ替えは、特定のタイプ内ではなく、タイプ全体で行なわれます。B2C Commerce で、クロスセリング、アップセリング などの推奨項目タイプごとに個別の並べ替え順が保持されることはありません。

B2C Commerce Einstein 辞書エントリの管理

Einstein Dictionaries の同義語グループの推奨項目を受け入れる、拒否する、または編集する。

必要なエディション

使用可能なソリューション: B2C Commerce

Einstein Dictionary エントリの同義語グループにアクセスするには、Business Manager で Einstein Search Dictionaries オプションにナビゲートします。

  1. Business Manager で、アプリケーションランチャーをクリックし、サイト | 検索 | 検索辞書 | Einstein 検索辞書の順に選択します。
  2. 推奨項目を受け入れる、または拒否するには、同義語グループのドロップダウン矢印をクリックします。
  3. 推奨項目を編集するには、既存の同義語グループをクリックします。
  4. 提案された同義語を追加または削除します。
  5. 変更を保存するには、受け入れるをクリックします。

B2C Commerce Einstein ステータスダッシュボードのモニター

カタログと注文のデプロイのステータスを確認し、データの品質を検証します。

必要なエディション

使用可能なソリューション: B2C Commerce
  1. Business Manager で、アプリケーションランチャーをクリックし、管理 > オペレーション > Einstein ステータスダッシュボードを選択します。
  2. Einstein のステータスを確認します。
    • 実行中 – Einstein のデプロイとプロビジョニングが進行中です。
    • エラー - 致命的なエラーが発生しました。Einstein の推奨項目はエラーが解決するまで利用できません。特定のエラーメッセージの詳細については、B2C Commerce Einstien セルフサービスサポートを参照してください。
    • 警告 - 情報を提供する警告です。Einstein Recommendations は機能しており、警告を解決せずにテストできます。特定の警告メッセージの詳細については、B2C Commerce Einstein セルフサービスサポートを参照してください。
    • 情報 – 情報を提供するメッセージです。アクションは必要ありません。
    • 未デプロイ – サイトが Einstein のデプロイのために構成されていません。
  3. データの品質列で、最後に Einstein にデプロイされたデータの品質評価を確認します。
    • なし - 表示するデータ品質の標準がありません。
    • 可 - Einstein による推奨項目用に商品を使用できるようにするには、以下のフィールドが必須です。カタログの商品の 75% 以上で次のフィールドのいずれかが空の場合、Einstein はデータ品質が公平であると見なし、フィールドを確認する必要があります。
      • URL のない商品
      • 画像のない商品
      • 在庫のない商品
    • 良 - 品質が「可」として認識されたフィールドがカタログの 75% 以上の商品で指定されており、Einstein はカタログのデータ品質を「良」とみなします。
  4. 最後のカタログのデプロイの日時と、次回にスケジュールされているカタログのデプロイの日時を確認します。
    • 赤いエラーのアイコン – カタログのデプロイの実行に失敗しました。
    • グリーンのチェックマーク – カタログのデプロイに成功し、デプロイが完了しました。
    • ブルーの実行中のドット – カタログのデプロイが実行中です。
  5. 最後の注文のデプロイの日時と、次回にスケジュールされている注文のデプロイの日時を確認します。
    • 赤いエラーのアイコン – 注文のデプロイの実行に失敗しました。
    • グリーンのチェックマーク – 注文のデプロイに成功し、デプロイが完了しました。
    • ブルーの実行中のドット – 注文のデプロイが実行中です。

パーソナルマーチャンダイジング

パーソナルマーチャンダイジングとは、顧客の過去の行動を基にして、マーチャントがコンテンツスロットを使用して顧客にプロモーションやコンテンツ情報を提供することです。この過去の行動は、アクティブマーチャンダイジングから得たデータです。

Salesforce B2C Commerce を使用してコンテンツスロットの設定を定義します。これらのコンテンツスロット設定は、顧客が属する顧客グループに基づいて、プロモーションのコンテンツをどのようにページスロットに読み込むかを指定できます。コンテンツスロット設定では、静的コンテンツアセット、商品、カテゴリ、フリーフォーム (HTML) がサポートされています。

また、ターゲットを絞ったキャンペーンやマイクロサイト、商品ライン用に、特定タイプの顧客を対象とする動的顧客グループを作成することもできます。たとえば、顧客の誕生月の間、ホームページでハッピーバースディ割引 バナーをログインした顧客に表示できます。

  • スロット設定に顧客グループが定義されていない場合は、ルールの評価中に Everyone (すべての顧客) グループの一部としてスロット設定が行われます。
  • スロット設定のルールに顧客グループが含まれている場合は、スロットの設定はそのグループの顧客に対してのみ有効です。
  • スロット設定のルールの一部として顧客グループが定義されている場合は、ルールの他の部分で対象となるのはそのグループの顧客のみです。

この機能を実装するには、次のように選択して設定を指定します。

  • マーチャントツール | サイト | オンラインマーケティング | コンテンツスロット
  • マーチャントツール | サイト | 顧客 | 顧客グループ

商品の推奨

B2C Commerce Einstein のセルフデプロイツールを使用すると、暗黙的に商品の推奨項目を生成できます。このトピックは、B2C Commerce に該当します。

メモ B2C Commerce ではこのアプローチがベストプラクティスだと考えています。

商品の推奨は、B2C Commerce Einstein を使用して動的に生成されます。商品の推奨項目は暗黙的な 予測と考えることができます。これに対して明示的な 推奨では、オブジェクトを直接リンクします。B2C Commerce Einstein はデータを収集し、機械学習モデルを使用してデータを分析し、Product Recommendations を生成します。

商品の推奨項目は、買い物客に商品 ID のリストとして表示されます。Einstein はRecommenderと呼ばれるビジネスルールを使用して、これらのリストの表示方法を制御します。

B2C Commerce Einstein での Recommender 出力のプレビュー

Recommender を追加または変更した後、Recommender の出力をプレビューして、推奨項目のリストが最終的に買い物客にどのように表示されるかを確認します。

必要なエディション

使用可能なソリューション: B2C Commerce

買い物客がストアフロントで特定の商品を表示すると、システムは自動的に特定のアンカー、つまり商品や商品カテゴリに関する情報を B2C Commerce Einstein に渡します。プレビューしたい Recommender タイプによっては、出力をプレビューするために、商品アンカー、商品名または商品 ID、カテゴリアンカー、あるいは商品カテゴリを指定しなければならない場合があります。

アンカーを指定すると、プレビュータブでサイトでの買い物客のアクティビティや選択がシミュレーションされます。Einstein はこの情報を使用して、提供したアンカー情報に基づいて買い物客に表示される推奨項目のプレビューを生成します。

たとえば、「商品から商品」または「セットを完成」の Recommender の出力をプレビューするには、商品アンカーを少なくとも 1 つ選択します。カテゴリ Recommender の出力で商品をプレビューするには、少なくとも 1つのカテゴリアンカーを指定します。

B2C Commerce Einstein は、指定されたアンカー情報を使用して、その商品または商品セットに適した推奨項目のリストを返します。

Recommender の出力をプレビューするには:

  1. Web ブラウザーで Einstein Configurator にアクセスします。
  2. 管理者から提供された認証情報を使用して、Einstein Configurator ツールにログインします。
  3. Recommender タブをクリックします。
  4. テーブルで Recommender をクリックして選択します。
    その Recommender のページが開きます。
  5. プレビュータブをクリックします。
  6. 特定の Recommender では、この表にまとめた情報をプレビューフィルターのフィールドに入力します。
    Recommender 指定する内容
    商品から商品 1 つ以上の商品アンカー(商品名または ID)
    カテゴリ内の商品 1 つ以上のカテゴリアンカー (カテゴリ ID)
    セットを完成 1 つ以上の商品アンカー(商品名または ID)
    メモ その他の Recommender では、Recommender 出力のプレビューにアンカーは必要ありません。
  7. 実行をクリックします。
    Recommender によって返されたすべての商品がページに表示されます。

B2C Commerce の推奨項目

B2C Commerce を使用し、さまざまなアプローチで推奨項目を実装します。

  • 商品の推奨
    B2C Commerce Einstein のセルフデプロイツールを使用すると、暗黙的に商品の推奨項目を生成できます。このトピックは、B2C Commerce に該当します。

Product Recommendations の B2C Commerce Einstein Recommender の構成

商品の Recommender を作成する場合は、使用する推奨タイプと戦略を指定します。また、ルールを追加して推奨項目を調整することもできます。

必要なエディション

使用可能なソリューション: B2C Commerce

Product Recommendations の Recommender を構成する前に、管理者によってサイトのカタログフィードと注文フィードが構成されていることを確認します。これらのフィードによって、Recommender を構成するために必要な情報が Einstein Configurator に提供されます。また、Einstein Configurator ツールを使用するためのアカウントが管理者によって設定されていることを確認してください。

Recommender を構成するには、以下の手順に従います。

  1. Web ブラウザーで Einstein Configurator にアクセスします。
  2. 管理者から提供された認証情報を使用して、Einstein Configurator にログインします。
  3. サイトの選択...リストから、サイトを選択します。
  4. サイトの推奨項目タブをクリックします。
  5. 新規 Recommender をクリックします。
    新規 Recommender の作成ダイアログが開きます。
  6. Recommender タイプの選択セクションで、Recommender タイプの 1 つを選択します。
  7. Recommender 名フィールドに、Recommender の名前を入力します。
    メモ Recommender 名は、サイトで一意の名前にします。名前には、ハイフン (-) とアンダースコア (_) を使用できます。名前の長さは 100 文字を超えることはできません。

    Recommender 名は保存後に変更することはできません。Recommender 名は、コンテンツスロット Recommender や Einstein ダッシュボードのレポートなど、他の場所に表示されます。ベストプラクティスとして、Recommender を適用する予定のページ名を Recommender 名の一部に含めるようにします。

  8. OK をクリックします。
    新規 Recommender の作成ダイアログが閉じ、Recommender の構成ページが開きます。
    メモ 新しく作成した Recommender は、この時点ではまだ保存されていません。後の手順で、保存をクリックした時点で保存されます。
  9. (オプション) 全般タブで次の操作を実行します。
    1. 推奨項目の最大数 フィールドで推奨項目数の上限を選択します。
    2. Recommender の説明を入力します。
      この説明は、Business Manager | コンテンツスロット | Recommender の選択で表示されます。
    3. 過去に購入した商品は推奨しないオプションを有効にして (チェックを付けて)、ドロップダウンメニューから値を選択します。

      このオプションを使用して、以前に購入された商品を Recommender が推奨するまでの待機期間 (7 日間、30 日間、60 日間、または 90 日間) を定義します。デフォルトの設定は 30 日間です。

    4. Recommender に固定したい商品を最大 2 つ選択します。
      固定商品は常に、Recommender の結果の最上位に表示されます。
    5. エンティティタイプにマスター商品またはバリエーショングループのいずれかを指定します。
      マスターカタログにバリエーショングループが含まれる場合は、エンティティタイプの設定を使用します。この設定を使用して、マスター商品またはバリエーショングループのレベルで推奨項目を提供します。
  10. (オプション) 戦略タブをクリックします。
    メモ このタブは、一部の Recommender では使用できません。
    戦略タブのテーブルには、各行に 1 つの戦略が表示されます。優先度が最高の戦略が一番上に表示され、その他の戦略がある場合は、優先度の順番にその下に表示されます。各戦略行の上向きと下向きの矢印アイコンを使用して、戦略を並べ替えます。
  11. (オプション) 別の戦略を作成するには、戦略の追加をクリックします。
    テーブルの下部に戦略の行が表示されます。次に、新しい戦略を選択します: [戦略名] フィールドで値を選択し、[ 保存 ] をクリックします。

    戦略を削除するには、テーブルで対応する行をクリックして、ゴミ箱 (削除) のアイコンをクリックします。

  12. (オプション) ルールタブをクリックします。
    Recommender ルールでは、買い物客に表示する商品を制御できます。
  13. (オプション) ルールの追加をクリックします。
    ルールテーブルに新しい行が表示されます。ここで値を選択し、保存をクリックして、ルールを作成します。
  14. 構成を保存するには、ページの右上隅にある保存をクリックします。
    メモ キャンセルをクリックするか、構成のページから移動すると、変更は破棄されます。

戦略とルールを構成する際には、それらをプレビューして、実行時に Einstein がストアフロントに渡す推奨項目を確認できます。

B2C Commerce Einstein でのルールの作成と適用

ルールでは、推奨商品 ID リストを、ランタイム時にストアフロントに渡す前に調整することができます。このトピックは、B2C Commerce に該当します。

メモ ルールの定義は必須ではありません。構成した Recommender がルールをもたないこともよくあります。ルールを使用しない場合は、リスト内のすべての商品 ID は、戦略から返されたそのままの順番でストアフロントに送られます。

任意の Recommender に対して最大 30 個のルールを作成して適用します。各ルールで、アクション、フィールド、および 1 つまたは複数の フィールド値 (または属性 ) を指定します。

B2C Commerce Einstein でルールが適用される場合、戦略によって返された ID リストの各商品がチェックされ、商品のフィールド値がルールで指定されている値と比較されます。商品のフィールド値がルールで指定されているフィールド値と一致する場合は、アクションが適用されます。

B2C Commerce Einstein のルールアクション

ルールのアクションは、B2C Commerce Einstein Recommender がリスト内の一致する項目をどのように表示、非表示、または移動するかを定義します。このトピックは、B2C Commerce に該当します。

メモ ルールを構成する場合は、競合するルールを作成しないように注意してください。たとえば、同じ商品品目を表示するルールと非表示にするルールを同時に作成してはなりません。また、同じ商品品目の表示位置を上げるルールと下げるルールを同時に作成すしてはなりません。その他のルールでも、同様です。

ルールのアクションには次の 4 種類があります。

  • 表示 - 指定したフィールド値に一致する項目のみが表示され、指定したフィールド値に一致しない項目は非表示になります。
  • 非表示 - 指定したフィールド値に一致する項目が非表示になります。
  • 上位に表示 - 一致する品目が上位に移動し、指定した値に一致する商品 ID が推奨項目に表示される商品 ID のリストに表示されるようになります。
  • 下位に表示 - 一致する品目が下位に移動し、指定した値に一致する商品 ID が推奨項目に表示される商品 ID のリストからはずれるようになります。

B2C Commerce Einstein のルールフィールドの値

ルールを作成する場合は、特定のルールフィールドに対して値を選択します。このトピックは、B2C Commerce に該当します。

B2C Commerce Einstein では、すぐに使用できる多数の属性がサポートされています。属性を構成する際には、以下を念頭に置いてください。

  • B2C Commerce Einstein では、ブール値、文字列、文字列のセット、および文字列の列挙の属性がサポートされています。
  • ストアフロントのパフォーマンスと買い物客の体験を保護するために、Einstein Configurator のルールでは一意性の割合が 25% を超えるフィールドは表示されません。一意性の割合は、一意の値の数をフィールド内の値の合計数で割って計算されます。
  • 一意性の割合が 25% 未満のすべてのフィールドは Web 使用可能にすることができます。Einstein は一意性が 25% 未満の「文字列のセット」フィールドを自動的に Web 使用可能としてマークします。ただし、他のすべての属性タイプについては、属性を Web 使用可能にするには Salesforce サポートケースが必要です。

Einstein 生成 AI の有効化

顧客が B2C ストアを訪れたときに最高のショッピング体験を提供するには、Salesforce 組織で生成 AI 機能を有効にします。

  1. Salesforce 組織で Einstein 生成 AI を有効化するには、次のタスクが必要です。
    • 組織内の Data 360 を確認する
    • Einstein 生成 AI をオンにする
    • Einstein Trust を設定する
    • Einstein データの収集と保存をオンにする
  2. すべてのタスクを完了したら、ブラウザーをリフレッシュします。

特殊なケースの明示的な推奨

特殊な状況における B2C Commerce の動作を理解することは重要です。

Business Manager 内で提供される機能と拡張可能な Recommendation (推奨項目) ビジネスオブジェクトの構成との間には依存関係があります。次の表は、B2C Commerce が特定の状況でどのように動作するかを説明しています。

シナリオ B2C Commerce の動作
推奨は存在するが、その推奨項目のタイプが RecommendationType 属性の値定義リストに含まれていなくなっている場合。 整数値が表示されますが表示名は表示されません。タイプ別フィルタリング用のドロップダウンメニューリストには、無効な値は含められません。既存の推奨項目を編集する場合は、これらの値を表示します。
RecommendationType 属性の属性値定義がない場合。 この場合は推奨項目を作成できません。Business Manager で推奨項目を作成する場合は、有効なタイプを選択します。
ソースまたはターゲットオブジェクト (たとえば、カテゴリまたは商品) がカタログからなくなっているが、関連付けられている推奨項目が削除されていない場合。

関連付けのない推奨項目は、Business Manager の推奨項目セクションに表示されるので、このセクションで削除できます。ソースおよびターゲットの両商品の SKU は表示されますが、利用不可 であることがわかる名前になっています。

関連付けのない推奨項目もエクスポートに含められます。存在しない商品を参照する推奨項目もインポートできますが、アプリケーションに影響はありません。
