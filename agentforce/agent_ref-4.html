ガイドラインと考慮事項

  • このアクションは Marketing Cloud キャンペーンでのみ使用されます。
  • このアクションは、検出された総計値に基づいて、今後のキャンペーンを改善するためのインサイト (提案) を出力します。
  • インサイトはキャンペーンの最初のフローに基づきます。キャンペーンの追加フローは評価されません。
  • このアクションは、Marketing Cloud の [キャンペーンを集計] アクションを呼び出します。
