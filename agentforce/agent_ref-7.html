Media Opportunity Summary and Prompt Template (メディア商談概要およびプロンプトテンプレート)

このエージェントアクションは、[レコード概要] 種別の [メディア商談を集計] プロンプトテンプレートをコールし、メディア商談の概要を生成します。プロンプトテンプレートでは、[Add Media Opportunity Summary to Prompt Template (Beta) (プロンプトテンプレートにメディア商談概要を追加 (ベータ))] フローを使用して、要約する情報を検索します。プロンプトテンプレートでは、商談とその関連する広告商談、見積、広告見積、ToDo の情報を使用して商談の概要が示されます。フローで複数の関連見積、広告見積、ToDo からの情報がプロンプトテンプレートに提供される場合、プロンプトテンプレートでは最新のレコードからの情報の集計が優先されます。

ガイドラインと考慮事項

  • アクションで生成される概要は、商談とその関連レコードで使用可能な情報によって異なります。
  • 生成される概要は 200 語に制限されます。
