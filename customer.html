CRM Analytics の基本操作

CRM Analytics（CRMA）は、Salesforce のデータをグラフや表で対話的に見られる分析ダッシュボードです。作成は不要で、閲覧される方は 見る・絞り込む・深掘りする・共有する の4つだけ覚えれば使えます。

ダッシュボードを開く

1

アプリランチャーを開く

画面左上の ⠿（アプリランチャー）をクリックし、「Analytics スタジオ」を選びます。レコードページやタブに埋め込まれている場合は、そのまま表示されます。

2

アプリ → ダッシュボードを選択

共有されているアプリ（フォルダ）を開き、目的のダッシュボードをクリックします。

4つの基本動作

① 見る

数値やグラフをそのまま確認します。タイトルや凡例で「何の指標か」を把握しましょう。

② 絞り込む（フィルタ）

上部のフィルタやトグルで、期間・地域・担当などを選ぶと、画面内の全グラフが連動して絞り込まれます。

③ 深掘りする（ドリル）

グラフの棒や扇をクリック →「深掘り」で内訳を表示。別の切り口でグルーピングし直すこともできます。

④ レコードへ移動

明細行をクリックすると、元の Salesforce レコード（商談・取引先など）へジャンプできる場合があります。

✅ 迷ったときの3ステップフィルタを全部クリア → 見たい期間を選ぶ → 気になる棒をクリックして深掘り。これでほぼ目的に届きます。

結果を活用する

操作内容場所
共有今のフィルタ状態のリンクや画像を共有右上メニュー → 共有
ダウンロードグラフのデータを CSV / 画像で出力（権限による）各ウィジェットのメニュー
通知（サブスクリプション）条件を満たしたら通知を受け取る右上メニュー → サブスクライブ
⚠️ データの鮮度についてCRMA は定期実行時点のデータを表示します（例：毎朝1回更新なら前日までの数値）。リアルタイムではない点にご注意ください。
💡 表示されない・見えないときダッシュボードやアプリが表示されない場合は、閲覧権限が付与されていない可能性があります。管理者へご連絡ください。

イベントモニタリング アプリの参照

Event Monitoring Analytics アプリは、「誰が・いつ・どこから・何をしたか」の操作ログ（ログイン、レポート出力、API 利用、ページ表示など）を CRMA ダッシュボードで可視化したものです。セキュリティ監査・利用状況把握・性能分析にご活用いただけます。

💡 このタブでできることアプリを新規に構築する手順ではなく、すでに用意されたイベントモニタリング ダッシュボードを「見て読み解く」ための参照ガイドです。

アプリを開く

1

Analytics スタジオを開く

アプリランチャー → 「Analytics スタジオ」。

2

「Event Monitoring」アプリを選択

アプリ一覧から Event Monitoring Analytics を開きます。

3

目的のダッシュボードを選ぶ

ログイン状況、レポート出力、API 利用などのダッシュボードが並んでいます。

主なダッシュボードと読み方

ダッシュボード見るもの気づけること
ユーザー活動 / 概要ログイン数・アクティブユーザー・地域別アクセス普段と違う時間帯・国からのログイン
レポート / データ出力誰がどのレポートを何件出力したか大量エクスポートなどの異常
API 利用状況API 呼び出し量・呼び出し元・種別特定ユーザー/連携の急増、上限の逼迫
ページ表示 (URI)よく見られる画面・遷移傾向使われていない機能／過剰なアクセス
パフォーマンスページ・処理の応答時間遅い画面・重い処理の特定

典型的な確認シナリオ

🔍 情報持ち出しのチェック

「レポート出力」ダッシュボードでユーザーと日付で絞り、普段0の人が急に大量出力していないかを確認。

🔍 不審なログインのチェック

「ユーザー活動」で時間帯やアクセス元（IP/国）を絞り、深夜・海外からのログインを確認。

🔍 API 急増のチェック

「API 利用状況」で呼び出し元別に見て、特定ユーザー/連携だけ桁違いに多くないか確認。

🔍 利用状況の把握

「ページ表示」で、導入した機能がどれだけ使われているか（定着度）を確認。

使い方は「操作方法」タブと同じ

絞り込み（フィルタ）→ グラフをクリックして深掘り、という基本操作は共通です。ユーザー・日付・IP の3つで切り分けるのが監査の基本動作です。

⚠️ データについてログは一定間隔で取り込まれるため、直近の操作は反映に遅延があります（多くは前日分までが安定して分析できます）。また、ログの保持期間には上限があります。
🔒 取り扱い注意イベントモニタリングには利用者の操作履歴が含まれます。閲覧・共有は権限のある担当者に限定してご利用ください。

B2B Marketing Analytics アプリの参照

B2B Marketing Analytics（B2BMA）は、Account Engagement（MCAE / 旧 Pardot）のマーケティングデータを CRM Analytics のダッシュボードで見るためのアプリです。メール・フォーム・キャンペーン・見込み客（プロスペクト）の成果を、CRM の商談データと合わせて分析できます。

💡 位置づけMCAE 本体（メール配信やスコアリングの設定）とは別に、その結果データを可視化する CRMA 側のアプリが B2B Marketing Analytics です。このタブは「見て読み解く」ための参照ガイドです。

アプリを開く

1

Analytics スタジオを開く

アプリランチャー → 「Analytics スタジオ」。

2

「B2B Marketing Analytics」アプリを選択

アプリ一覧から開きます。

3

ダッシュボードを選ぶ

キャンペーン別、メール別、パイプライン貢献などのダッシュボードが並びます。

主なダッシュボードと読み方

ダッシュボード見るものわかること
マーケティング マネージャ / 概要リード獲得数・キャンペーン全体の成果どの施策が成果につながっているか
メール パフォーマンス開封率・クリック率・配信数の推移効果の高いメール・件名の傾向
エンゲージメント / スコアリングプロスペクトの反応・スコアの分布ホットな見込み客の状況
パイプライン貢献マーケ施策がどれだけ商談・売上に寄与したかマーケティングの ROI

MCAE 用語のミニ辞書

用語意味
プロスペクトMCAE 上の見込み客レコード（メールアドレス単位）
スコアプロスペクトの行動（開封・クリック等）の活発さを表す点数
グレードターゲット像への合致度（A〜Fなど）
エンゲージメントスタジオMCAE のシナリオ配信（ステップメール）機能
キャンペーン施策の単位。CRM の商談やリードに紐づけて成果を測る

典型的な確認シナリオ

📈 効果の高いメールを知る

「メール パフォーマンス」で開封率・クリック率を並べ、成果の高い件名や配信時間帯の傾向を確認。

📈 施策の売上貢献を見る

「パイプライン貢献」で、キャンペーン別に商談化・売上への寄与を確認し、次の予算配分の判断材料に。

使い方は共通です

フィルタで期間・キャンペーン・チャネルを絞り、グラフをクリックして深掘りする、という操作は「操作方法」タブと同じです。

⚠️ データについてB2BMA のデータも定期実行時点のものです。MCAE 側の最新の反応がダッシュボードに出るまで時間差があります。
