Marketing Cloud Engagement

AI を搭載したエンゲージメントマーケティングツールを使用してリレーションを構築します。Marketing Cloud Engagement には、メッセージングと Web コンテンツの設計、顧客エンゲージメントの整理と追跡、複雑なマーケティングキャンペーンの自動化に役立つアプリケーションが用意されています。

メモ Marketing Cloud EngagementまたはExactTargetの各エディションに含まれるサービスの詳細については、価格設定ドキュメントを参照してください。
  • Marketing Cloud Engagement+ の使用開始
    Marketing Cloud Engagement+を使用すると、Marketing Cloud Nextの次世代機能にアクセスできます。また、長年にわたって作成したキャンペーン、データエクステンション、ジャーニーもすべてMarketing Cloud Engagementに保持されます。両方の世界の良いところです。
  • Marketing Cloud Engagement テナント種別
    Marketing Cloud Engagement のさまざまなタイプのテナントについて説明します。
  • Salesforceホスト環境とHyperforce環境の比較
    Marketing Cloud Engagement は 2 つの環境でホストされます。最初の環境では、Salesforce がホスト、運用、維持するサーバーを使用します。2つ目の環境はHyperforceと呼ばれ、パブリック クラウド サービス上に構築されています。Hyperforce には、Salesforce でホストされるインスタンスよりもいくつかの利点があります。また、Salesforce でホストされる環境で使用可能な機能と Hyperforce で使用可能な機能には違いがあります。
  • Marketing Cloud Engagement の設定
    Marketing Cloud Engagement の [設定] は、アカウントを表示および管理するための一元的な場所です。また、その他の有用な情報源へのリンクも含まれています。
  • Marketing Cloud Engagement のパッケージマネージャー
    パッケージマネージャーを使用して会社または業種固有のソリューションをバンドルし、ビジネスユニット全体にリリースすることで、ベストプラクティスを拡張し、価値実現までの時間を短縮します。
  • Marketing Cloud Engagement でのトランザクション送信の調整
    Marketing Cloud Engagement は、SMS およびトランザクションのメール配信とケイデンスに関する規制報告要件を満たすために、これらのメッセージの配信情報を取得します。また、最終的な配送状況も [送信済み] または [未送信] として取得されます。
  • Marketing Cloud Engagement インスタンスの決定
    Marketing Cloud Engagement アカウントの状況を確認するには、インスタンスのメンバー ID (MID) を使用します。Web Collect URL を設定する場合や、Marketing Cloud Engagement API の URL エンドポイントを取得する場合にも、MID を把握しておくと役立ちます。
  • Marketing Cloud Engagement サブスクリプションの期限切れ
    Marketing Cloud Engagement サブスクリプションの有効期限が切れると、アカウントへのアクセスが 90 日間制限されます。90 日以内にアカウントを更新しないと、すべてのアクセス権が取り消されます。
  • 一時停止中の Marketing Cloud Engagement アカウント
    一時停止中の Marketing Cloud Engagement アカウントへのアクセスは制限され、問題を解決して再有効化しないとアカウントが削除されます。サービスを再有効化するには、Salesforce アカウントエグゼクティブにお問い合わせください。
