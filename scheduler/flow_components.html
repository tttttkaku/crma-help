レコードページへの発信フローの埋め込み (省略可能)

フローをレコードページに埋め込むと、ユーザーはページから直接予定をスケジュールしたり変更したりできます。クイックアクションを使用する必要はありません。クイックアクションでは、フローが別のウィンドウで起動され、ページの詳細へのユーザーのアクセスがブロックされます。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
  1. Salesforce Scheduler フローを埋め込むレコードページで、[設定] から [編集ページ] を選択します。
  2. フローコンポーネントをページにドラッグします。
    警告 マルチリソーススケジュールを有効にしている場合は、フローコンポーネントをページのメイン領域に追加します。マルチリソーススケジュールが有効な場合、Salesforce Scheduler フローはタブ、またはレコードページのサイドバーに追加されると機能しません。
  3. [プロパティ] ペインの [フロー] リストで、追加する Salesforce Scheduler フローを選択します。
  4. 変更内容を保存します。

フロー画面での表示ラベルの変更

会社の用語を使用するには、サービスリソース、サービステリトリー、サービス予定、作業種別グループ、作業種別のタブ名と項目名を変更します。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
必要なユーザー権限
タブと項目の名称を変更する 「アプリケーションのカスタマイズ」または「翻訳の管理」

タブと表示ラベルの名称を変更すると、これらのオブジェクトを使用するすべてのアプリケーションに変更内容が表示されます。たとえば、サービス予定オブジェクトは Salesforce Field Service でも使用されます。サービス予定オブジェクトのタブ名と表示ラベルを変更すると、Field Service ユーザーにも新しいタブ名と表示ラベルが表示されます。

  1. [設定] から、[クイック検索] ボックスに「タブと表示ラベルの名称変更」と入力し、[タブと表示ラベルの名称変更] を選択します。
  2. [言語の選択] ドロップダウンリストから、表示ラベルを変更する言語を選択します。
  3. サービス予定など、名前を変更するエンティティの横にある [編集] ボタンをクリックします。
  4. 新しい名前の単数形と複数形を入力し、該当する場合は [母音で始まる場合はチェック] をオンにします。
  5. [次へ] をクリックします。
  6. 必要に応じて項目の表示ラベルを変更し、新しい名前が母音で始まるかどうかを指定します。
    たとえば、[予定種別] を [カテゴリ] に変更し、[母音で始まる場合はチェック] をオフにします。
    メモ 元のタブ名と項目名に戻すには、タブ名の [リセット] ボタンをクリックします。
  7. 変更内容を保存します。

フローを起動するクイックアクションの作成

クイックアクションを使用すると、数回のクリック操作だけでワークフローの起動やナビゲーションなどのアクションを実行できます。たとえば、招待をすばやく生成するには、[Generate Appointment Invitation (予定招待を生成)] フローを実行するクイックアクションを作成します。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
  1. サービスリソースのオブジェクト管理設定から、[ボタン、リンク、およびアクション] に移動して、[新規アクション] をクリックします。
  2. [アクション種別] で、[フロー] を選択します。
  3. クイックアクションで実行する既存のフロー ([パートナーの予定招待を生成] など) を選択します。
  4. [標準の表示ラベル種別] 選択リストで [なし] を選択します。
  5. [表示ラベル] 項目に表示ラベル (「ゲストの招待」など) を入力します。
  6. 必要に応じて、アクションの説明を入力し、アイコンを選択できます。
  7. 変更内容を保存します。

予定通知を送信するレコードトリガーフローの作成

レコードトリガーフローを使用して、今後の予定をユーザーに通知します。通知を受信者グループにメールで送信することも、各受信者に個別に送信することもできます。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
必要なユーザー権限
Flow Builder でフローを開く、編集または作成する 「フローの管理」
フローを実行する 「フローの実行」
  1. [設定] で、[クイック検索] ボックスに「フロー」と入力して、[フロー] を選択し、[新規フロー] をクリックします。
  2. [Start From Scratch (ゼロから開始)] を選択し、[Next (次へ)] をクリックします。
  3. [レコードトリガーフロー] を選択し、[作成] をクリックします。
  4. フローを設定します。
    1. [オブジェクト] で、[サービス予定] を選択します。
    2. [フローをトリガーする条件] で [レコードが作成された] を選択します。
    3. [条件の要件] で [すべての条件に一致 (AND)] を選択します。
    4. 条件を追加します。たとえば、AppointmentType または EngagementChannelType のいずれかの条件を追加して、[次の文字列と一致する] [ビデオ] に設定します。
    5. [アクションと関連レコード] を選択します。
    6. [トリガーレコードの元のトランザクションが正常にコミットされた後に外部システムにアクセスするには、非同期に実行パスを含めます。] を選択し、[完了] をクリックします。
  5. [自動レイアウト] をクリックし、[自由形式] を選択します。
  6. [保存] をクリックします。
  7. フローの表示ラベルと API 参照名を入力して、変更内容を保存します。

受信者としてサービス予定レコードに関連付けられたサービスリソースをメール通知リストに追加します。

別のユーザーとしての Salesforce Scheduler フローのデバッグ

別のユーザーとしてログインすることなく、そのユーザーとしてフローをテストおよびデバッグします。特定のユーザーに表示されるフローのデバッグログの内容を確認して、フローをトラブルシューティングできます。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
  1. [設定] の [クイック検索] ボックスに「プロセスの自動化設定」と入力し、[プロセスの自動化設定] を選択します。
  2. [システム管理者が他のユーザーとしてフローをデバッグできるようにする] チェックボックスをオンにします。
  3. 変更内容を保存します。
  4. Flow Builder で [デバッグ] をクリックし、[別のユーザーとしてフローを実行] チェックボックスをオンにします。
  5. フローの実行中にシミュレーションするユーザーを選択します。
  6. フローのデバッグの実行は、シミュレーションされたユーザーで開始されきます。デバッグの詳細を確認します。

Lightning Out を使用した Web サイトへの [受信 新規ゲスト予定] フローの追加

未認証のユーザーに [受信 新規ゲスト予定] フローへのアクセス権を付与する会社の Web サイト (外部 Web サイト) に Lightning Out 連動関係アプリケーションを追加します。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition

ゲストユーザーに必要なユーザー権限とオブジェクト権限が付与されていることを確認します。詳細は、「ゲストユーザーへの必要なユーザー権限およびオブジェクト権限の付与」および「予定をスケジュールするゲストユーザーの共有ルールの作成」を参照してください。

メモ Scheduler フローが外部 Web サイトでホストされている場合、フローでは、ゲストユーザープロファイルで設定されている言語ではなくブラウザーで設定されている言語を使用します。
  1. [受信 新規ゲスト予定] 標準フローテンプレートのコピーを作成します。
  2. UI 要素が正確に配置されるように、次の <style> タグを Web ページに追加します。 
    <style>
        .slds-visual-picker_vertical .slds-visual-picker__figure {
            height: inherit !important;
        }

        .runtime_appointmentbookingFlowLocation .slds-visual-picker_vertical {
            display: inline-flex !important;
        }
</style>
  3. JavaScript Lightning Out ライブラリへの参照を追加するには、script タグを使用します。
    1. Lightning Out JavaScript ファイルを Web ページに追加します。 
      <script src="https://YourSiteDomain/lightning/lightning.out.js"></script>
    2. https://YourSiteDomain/ を Experience Cloud サイト URL に置き換えます。
      警告 script タグに SiteURL を追加すると、フローは機能しません。
  4. Web ページで LightningOutGuest アプリケーションを読み込んで有効化するには、次の手順を実行します。
    1. 標準の Lightning Out JavaScript コードを追加します。 
      <script>
    $Lightning.use("runtime_appointmentbooking:lightningOutGuest",
        function() {                  // Callback once framework and app load
            $Lightning.createComponent(
                "lightning:flow",    // top-level component of your app
                { },    // attributes to set on the component when created
                "lexcontainer",    // the DOM location to insert the component
                function(component) {            // API name of the Flow
                    component.startFlow("Salesforce_Scheduler_Unauthenticated");
                }
            );
        },    'https://YourSiteDomain/SiteURL/'  // Site endpoint
    );
</script>
    2. lexcontainer を、Lightning コンポーネントを挿入するページの場所に置き換えて、別のタグから Lightning コンポーネントを呼び出します。

      Lightning コンポーネントを呼び出すサンプルコードを次に示します。

      <div id="lexcontainer">
<p>Invoke the Lightning Component specified in the Script.</p>
</div>
    3. https://YourSiteDomain/SiteURL を、必要なオブジェクト権限が付与された [受信 新規ゲスト予定] フローが含まれる Experience Cloud サイトの URL に置き換えます。
  5. 外部サイトのオリジン URL を CORS に追加するには、次の手順を実行します。
    1. [設定] で、[クイック検索] ボックスに「CORS」と入力して、[CORS] を選択します。
    2. [新規] をクリックします。
    3. [オリジンの URL パターン] 項目に外部サイトのオリジン URL を入力します。
    4. 変更内容を保存します。
    メモ Scheduler フローが外部 Web サイトでホストされている場合、リソースカードにはサービスリソースの写真ではなく標準画像が表示されます。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition

Salesforce Scheduler に用意されたフロー画面のコンポーネントとアクション

Salesforce Scheduler には、フローを作成してフローを変更するための追加のフロー画面コンポーネントとアクションが用意されています。

必要なエディション

使用可能なインターフェース: Lightning Experience。
使用可能なエディション: Enterprise Edition および Unlimited Edition
メモ Salesforce Scheduler フロー画面コンポーネントを実行するには、Lightning ランタイムが必要です。

フロー画面コンポーネントには、フロー変数に保存される入力属性と出力属性が含まれます。入力属性値を編集して、画面に表示されるデフォルト値とオプションを制御できます。画面のユーザーアクションによって出力属性値が決まります。Salesforce Scheduler では、ユーザーが次の画面に移動したときにフロー変数の出力属性値が更新されます。

ユーザー入力を取得するためにフロー画面コンポーネントを追加したら、アクションを使用して変更を保存します。

  • フロー画面コンポーネント: Add Service Appointment Attendees (サービス予定出席者の追加)
    ユーザーは、[サービス予定出席者を追加] コンポーネントを使用して、個人取引先、取引先責任者、リードレコードを被招集者としてサービス予定に追加できます。
  • フロー画面コンポーネント: 予定の予約の招待の詳細
    このコンポーネントを使用すると、ユーザーは予定招待の詳細を指定できます。
  • フロー画面コンポーネント: レートの設定
    ユーザーは [レートを設定] コンポーネントを使用して、選択した作業種別とサービステリトリーのレートカードを設定できます。
  • フロー画面コンポーネント: Filter Service Appointment Reassignments (サービス予定の再割り当てを絞り込む)
    このコンポーネントを使用すると、ユーザーはサービス予定を一括で再割り当てする条件を指定できます。
  • フロー画面コンポーネント: サービス予定の変更またはキャンセル
    ユーザーは、[サービス予定を変更またはキャンセル] コンポーネントを使用して、サービス予定を変更およびキャンセルできます。
  • フロー画面コンポーネント: 複数選択待機リスト
    このコンポーネントを使用すると、待機リストの作業種別のリストまたはサービスリソースのリストを選択できます。
  • フロー画面コンポーネント: 支払リンク
    ユーザーは支払リンクコンポーネントを使用して支払リンクを生成し、他のコミュニケーションチャネルを使用してメールで送信したり共有したりできます。
  • フロー画面コンポーネント: 支払ページ
    ユーザーは支払ページコンポーネントを使用して、サービス予定の支払に関する支払の詳細を入力できます。
  • フロー画面コンポーネント: 支払設定のプレビュー
    ユーザーは [支払設定をプレビュー] コンポーネントを使用して、選択した作業種別、サービステリトリー、および設定されたレートをプレビューできます。
  • フロー画面コンポーネント: サービス予定を再割り当て
    このコンポーネントを使用すると、ユーザーは、既存のサービスリソースのサービス予定を再割り当てする代替サービスリソースを選択できます。
  • フロー画面コンポーネント: 受信または送信サービス予定をレビュー
    ライセンスユーザーおよびコミュニティユーザーがサービス予定を表示および変更できるようにします。
  • フロー画面コンポーネント: サービス予定をレビュー
    ゲストユーザーがサービス予定を表示できるようにします。
  • フロー画面コンポーネント: 予定の予約の URL を確認
    このコンポーネントを使用すると、ユーザーは予定の予約用に作成された招待 URL を確認できます。
  • フロー画面コンポーネント: アクション可能リストメンバーの状況を選択
    このコンポーネントを使用すると、ユーザーは [アクション可能リスト] 画面で更新されるアクション可能リストメンバーの状況を選択できます。
  • フロー画面コンポーネント: 予定の被招集者を選択
    このコンポーネントを使用すると、ユーザーは予定招待のサービスリソースを選択できます。
  • フロー画面コンポーネント: 予定種別を選択
    ユーザーが電話、支店、ビデオ通話などの予定種別を選択できるようにします。
  • フロー画面コンポーネント: 支払パラメーターの選択
    ユーザーは [支払パラメーターを選択] コンポーネントを使用して、オブジェクト (サービステリトリーや作業種別など) を選択して支払設定を定義できます。
  • フロー画面コンポーネント: サービス予定時間を選択
    ユーザーがサービス予定時間を選択できるようにします。
  • フロー画面コンポーネント: サービスリソースを選択
    ユーザーがサービスリソース (予定の被招集者) を選択できるようにします。
  • フロー画面コンポーネント: サービスリソースを選択
    [サービスリソースを選択] フロー画面コンポーネントを使用すると、ユーザーは取引先、ケース、リード、または商談レコードのサービスリソース (内部の予定の被招集者) を選択できます。
  • フロー画面コンポーネント: サービスリソースおよびサービス予定時間を選択

フローアクセスを使用して、Salesforce Schedulerフロープロセス種別で、ユーザーレコード、プロファイル、または権限セットに基づいてフローを編集および実行できるユーザーを制限します。より詳細なセキュリティを個々のフローに適用するには、フローのデフォルトの動作を上書きします。そして、ユーザープロファイルまたは権限セットに基づいてフローへのアクセス権を付与します。

  2. 設定するフローを編集します。

  3. Flow Builder で、関連するフロー画面コンポーネントを使用してフロー画面を編集します。
  4. フロー画面コンポーネントを選択します。
  5. プロパティペインで、[詳細] を展開します。[再アクセス画面の値] で、[入力を更新してフローの他の場所での変更を組み込む] を選択します。
  6. 各フロー画面に対してステップ 3 ～ 5 を繰り返します。
  7. 変更を保存して、フローを有効化します。
